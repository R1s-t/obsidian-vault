# 命令行模式与Python交互模式
## 命令行模式
- 终端窗口PowerShell
- 执行`python **.py`可直接运行一个`.py`文件，`**`为文件名
- 运行`.py`文件只能在命令行模式下运行
- ==要事先切换到`.py`所在目录==，用`cd ****`或绝对路径`cd *:\**\**\**`，`cd`是切换命令
- 如果要切换盘符，如切换到D盘，输入`D:`，无`cd`命令
- 命令行模式一次性运行`.py`文件内的所有代码，不会自动打印每一行代码的结果，要用`print()`
- 提示符为`PS C:\>`,`C`为盘符
## Python交互模式
- 在命令行模式输入`python`进入Python交互模式，输入`exit()`退出至命令行模式
- 通过开始菜单输入`Pyhton (command line)`直接进入Python交互模式，输入`exit`直接关闭窗口%%不会回到命令行模式%%
- 提示符为`>>>`
- 提示符`...`表示接着上行继续输入
- 输入一行，执行一行，自动打印每一行Python代码结果
- 主要用于调试代码，不是正式运行Python的环境
# 可能的问题
- `SyntaxError`表示输入的代码有语法错误
- `invalid character`表示有无法识别的字符%%通常为中英文字符混用%%
- Windows上不能直接运行`.py`文件%%此处直接运行指`.exe`文件运行方式%%
- 不要用Word和Windows自带的记事本，Word保存的不是纯文本文件，记事本会在文件开始的地方加几个特殊字符（UTF-8 BOM)，导致程序运行出现错误
- 文件名只能是英文字母、数字和下划线的组合，必须以`.py`结尾
