# 微项目练习清单

> 微项目不是「第八个项目」，是零件、热身和碎片时间填充。
> 大部分已被一生一芯吸收（UART / SPI / AXI-Lite 都在 SoC 外设里），所以只挑一生一芯**不教**、但面试**会问**的。

配套：[[考研/竞赛与项目全周期规划（2026-2028）|全周期规划]] · [[入口/微电子学习资源与刷题工具|学习资源与刷题工具]]

## 验收标准（三选一，没有就不算做完）

1. **一张波形图** —— GTKWave 截图，标出关键信号和时刻，一句话说明「这张图证明了什么」。
2. **一个全过的 testbench** —— 列出覆盖了哪些 case（正常 / 边界 / 异常）。
3. **一次通过的 formal proof** —— 列出断言（assert / assume / cover）。

三个都没有的项目，在复试里等于没做。

## A. 数字基础零件（5–15h）

| # | 项目 | 工时 | 为什么值得做 |
|---|---|---|---|
| A1 | 同步 FIFO（含 almost_full / empty） | 10h | 状态机与指针的基本功，形式验证的第一块试验田 |
| A2 | **异步 FIFO + CDC 同步器** | 15h | 面试最高频，一生一芯不教；格雷码指针 + 两级同步 |
| A3 | 仲裁器（固定优先级 / 轮询 / 加权） | 8h | 总线与 NoC 的最小单元 |
| A4 | 格雷码计数器 | 5h | A2 的前置 |
| A5 | AXI-Lite 从机 | 15h | 挂外设、SoC 集成的必备 |

## 只做 6 个的话，按这个顺序

1. **B1 单周期 RV32I**（12h）——寒假第一周，验证工具链和手感
2. **A2 异步 FIFO + CDC**（15h）——面试最高频
3. **B2 直接映射 Cache**（15h）——CPU 的必答题
4. **C3 RV32I 汇编器**（15h）——EDA 线零件
5. **A5 AXI-Lite 从机**（15h）——SoC 集成
6. **C1 cocotb + Verilator**（12h）——验证能力的凭据

合计 84h，正好铺满寒假的两个碎片周。

## 三条纪律

1. **不超过 5 个**。陪衬层超过 5 个开始扣分——复试只问 1–2 个项目，做到细节为止。
2. **每个都要进 GitHub**，repo 名带 `xmu-` 或 `rv-` 前缀，README 三段：问题 / 方案 / 数据。
3. **同一个坑不写两次**。写博客就是把坑变成可检索资产，下次不再踩。
