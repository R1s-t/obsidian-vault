# Obsidian 配置指南

> 基于纸笔+数字混合笔记体系，给出 Obsidian 的具体配置方案。
> 本指南的仓库结构设计为**终身知识库**——从学生时代到职业生涯，框架不变，只增不减。
> 更新日期：2026-08-04

---

## 一、仓库（Vault）设置

### 1.1 建议：一个仓库，终身使用

不要为每门课建单独的 vault——那样 `[[双向链接]]` 无法跨课程工作。也不要毕业后重建。整个微电子生涯的所有笔记放在同一个仓库里。

```
建议路径：~/Documents/微电子笔记库/
```

### 1.2 基础设置

打开 **设置 → 文件与链接**：

| 设置项 | 建议值 | 原因 |
|--------|--------|------|
| 新建笔记的默认位置 | `指定的文件夹` → `Inbox/` | 新笔记先进入收件箱，周末归档时再归类 |
| 附件存放路径 | `指定的文件夹` → `Attachments/` | 所有截图、照片集中存放，笔记正文不乱 |
| 内部链接格式 | `尽可能简短` | `[[MOSFET阈值电压]]` 而不是 `[[文件夹/MOSFET阈值电压]]` |
| 默认编辑模式 | `实时预览` | 写 markdown 时即时看到渲染效果 |

打开 **设置 → 编辑器**：

| 设置项 | 建议值 |
|--------|--------|
| 默认视图模式 | `实时预览` |
| 显示行号 | 关（写笔记不是写代码） |
| 拼写检查 | 关（中英混输误报太多） |

## 二、文件夹结构（终身知识域）

### 2.1 设计原则

- **知识域名字本身就够终身**：模拟电路的知识永远在 `模拟电路与系统/`，不需要编号来锚定
- **域内二级目录从 1 起，只表示顺序**——`1-运算放大器`、`2-基准与偏置`……序号是"第几个"，不是"归哪个域"
- **第三层及以下不编号**——自由生长，没有数量限制
- **顶层只有两个序号**——`0-入口`、`1-时间表`，纯粹为了置顶，不是分类
- **标签跟身份走**——学生阶段用 `#课程/xxx`、`#学期/xxx` 标签标记，毕业后不再新增这些标签，但知识域不变

### 2.2 完整结构

见 [[库说明]] 的目录表——那是唯一会跟着实际改动更新的一份。这里不再抄一份，抄了必然过期。

### 2.3 编号规则速查

```
顶层        只有两个目录带序号
─────    ─────────────────
0-入口     导航（首页、库说明、收藏、清单）
1-时间表   项目规划、时间线、周任务单
其余 28 个目录    不带序号，按名字排序

域内        知识域的二级目录从 1 起顺序编号
─────    ─────────────────
1, 2, 3…   该域内的第几个主题，不带连号（不写 51-、62-）
每个域独立    半导体物理与器件/1-… 和 工艺与制造/1-… 同时存在
第三层+    不编号，自由生长
```

### 2.4 为什么这样设计

- **不是按课程分的**——「模拟电子技术」这门课的内容可能同时进入器件、模拟、数字三个域
- **没有年级色彩**——毕业后不会出现「大二的文件夹还在但大三的已经不看了」
- **顶层不编号**——编号是"置顶工具"不是"分类工具"。给 30 个目录编号，等于给 30 行都加了个没信息量的前缀，还让侧边栏无法按名字排序
- **域内序号从 1 起**——归属由父目录名已经说清楚了，再在数字里编一遍域号（`51-光刻`、`62-Synopsys`）只是重复；而且跨域连号会让新增/删除目录时数字出现空档
- **Templates 和 Attachments 无编号**——它们是基础设施，不是知识。判断标准：编号的你有东西要学，没编号的你只是用它

## 三、必装插件

### 3.1 核心功能插件

| 插件 | 类型 | 用途 | 优先级 |
|------|------|------|--------|
| **模板** | 内置核心插件 | 一键插入笔记模板。注意：这是 Obsidian 的**核心插件**（中文名「模板」），**不是**社区插件 Templater。设置 → 核心插件 → 开启「模板」即可 | ⭐⭐⭐ |
| **Templater** | 社区插件 | 如果你在模板中需要日期变量（如 `{{date}}`）、文件标题变量或光标定位，再安装 Templater。内置模板足够日常使用 | ⭐⭐ |
| **Quick Add** | 社区插件 | 用快捷键选择模板新建笔记 | ⭐⭐⭐ |
| **Excalidraw** | 社区插件 | 在 Obsidian 内手绘电路图、框图、流程图 | ⭐⭐⭐ |
| **Latex Suite** | 社区插件 | 加速 LaTeX 公式输入（片段触发） | ⭐⭐ |
| **Admonition** | 社区插件 | 漂亮的提示框（定理/注意/误区） | ⭐⭐ |

### 3.2 增强插件（按需）

| 插件 | 用途 | 何时需要 |
|------|------|---------|
| **Dataview** | 自动生成索引：列出所有标记 `#课程/模拟电子技术` 的笔记 | 笔记超过 100 篇后 |
| **Kanban** | 看板视图，管理设计项目的迭代进度 | 做项目/流片时 |
| **Calendar** | 日历视图，查看每日创建的笔记 | 想按时间回溯 |
| **Tag Wrangler** | 批量重命名标签 | 标签体系重构时 |

### 3.3 数学相关

**Latex Suite 的设置**：在插件设置中启用默认的 snippets。常用片段：

| 输入 | 触发 | 输出 |
|------|------|------|
| `dm` | → | `$$ ... $$`（行间公式） |
| `ee` | → | `e^{}` |
| `ff` | → | `\frac{}{}` |
| `sq` | → | `\sqrt{}` |

## 五、标签体系

### 5.1 设计原则

**标签跟身份走，文件夹跟知识走。** 学生阶段用课程/学期标签，毕业后不再新增这些标签，但知识域结构不变。

### 5.2 标签分类

**内容类型标签**（永久使用）：

```
#概念卡片    — 概念理解型笔记
#公式推导    — 公式推导型笔记
#EDA操作     — 工具操作记录
#论文        — 论文阅读笔记
#踩坑        — 所有踩坑记录（跨域统一标签）
#需要更新    — 标记回头看时觉得太浅的旧笔记
#todo        — 标记需要后续处理的笔记
```

**学生身份标签**（毕业后不再新增，但保留历史）：

```
#课程/模拟电子技术
#课程/数字电子技术
#课程/半导体物理
#课程/固体物理
#学期/大二上
#学期/大二下
```

**职业身份标签**（入职后启用）：

```
#项目/xxx芯片流片
#评审/设计评审记录
#竞品/xxx公司xxx芯片
```

### 5.3 为什么这样分

- 标签的作用是**跨文件夹检索**——比如查 `#踩坑` 能看到所有域中犯过的错
- 学生时期想知道「模拟电子技术这门课学了什么」→ 查 `#课程/模拟电子技术`
- 工作后想知道「这个项目涉及哪些域的知识」→ 查 `#项目/xxx流片`
- **关键**：毕业后你不再需要按课程检索，但你当时写的笔记本身还在域里，知识没丢

## 六、学生阶段对接指南

### 6.1 核心操作：归档时拆解

你现在是按课程上课，但笔记按知识域存储。**同一堂课的内容可能进入不同域**——归档时自己判断。

**示例**：「模拟电子技术」课堂讲了差分放大器：

```
纸质草稿 → 周末归档 →

放入 模拟电路与系统/
  ├── 在 域总览 的关系图上添加「差分对」节点
  ├── 1-运算放大器/差分对.md    ← 概念卡片
  └── 1-运算放大器/差分对-推导.md ← 关键推导照片

标签：
  - 概念卡片
  - 课程/模拟电子技术
  - 学期/大二下
```

**示例**：「模拟电子技术」课堂讲了 PN 结的电容特性：

```
放入 半导体物理与器件/
  ├── 4-PN结/PN结电容.md        ← 概念卡片
  └── 4-PN结/PN结电容-推导.md    ← 公式推导

放入 模拟电路与系统/
  └── 1-运算放大器/密勒效应与带宽.md ← 应用视角（链接回上面的 PN 结电容）

标签：
  - 概念卡片 / 公式推导
  - 课程/模拟电子技术
  - 学期/大二下
```

### 6.2 期末复习

不翻教材，不翻纸质本。用标签聚合：

1. 在 Obsidian 搜索 `#课程/模拟电子技术` → 这门课的所有笔记
2. 或用 Dataview 创建该课程的汇总页：

```markdown
# 模拟电子技术 - 复习总览

```dataview
TABLE type AS 类型, created AS 日期
FROM #课程/模拟电子技术
SORT created ASC
```

3. 打开各域的 `x0-总览与索引.md` → 看概念关系图，找到卡住的节点
4. 卡住的节点回看完整卡片
5. 仍有疑问的回到教材

### 6.3 毕业后

不需要任何迁移。`#课程/xxx` 标签不再新增，但你会开始用 `#项目/xxx`、`#评审/xxx`。仓库结构不动，只是活跃的域可能从 10-60 转到了 20-90。

## 七、Excalidraw 使用场景

Excalidraw 是 Obsidian 里的手绘插件，可以直接在笔记中画图。适合以下场景：

| 场景 | 用 Excalidraw 还是纸笔拍照？ |
|------|---------------------------|
| 课堂速记画图 | 纸笔（速度更快） |
| 章末概念关系图 | 纸笔（A4 纸自由度高） → 拍照 |
| 电路小信号模型 | 纸笔 → 拍照（标注自由） |
| 设计项目的架构框图 | **Excalidraw**（需要反复修改，数字版易编辑） |
| 数字系统框图 | **Excalidraw** |
| 论文笔记中的架构图 | **Excalidraw**（与笔记紧密绑定） |

简单原则：**需要反复修改的用 Excalidraw，一次性草稿用纸笔。**

在笔记中嵌入 Excalidraw 绘图：

```markdown
> 原图已不在库中（`两级运放架构.excalidraw`，讨论两级运放架构）
```

## 八、Dataview 自动索引

笔记超过 100 篇后，手动管理索引变得困难。Dataview 可以自动生成动态列表。

### 8.1 所有概念卡片索引

创建 `概念卡片索引.md`（放在根目录）：

```markdown
# 概念卡片索引

```dataview
TABLE 一句话, created
FROM #概念卡片
SORT created DESC
```

### 8.2 所有踩坑记录

创建 `踩坑索引.md`：

```markdown
# 踩坑索引

```dataview
TABLE file.cday AS 日期, tool AS 工具
FROM #踩坑
SORT file.cday DESC
```

### 8.3 域内笔记汇总

在每个 `x0-总览与索引.md` 中：

```markdown
## 本域全部笔记

```dataview
TABLE type AS 类型, created AS 日期
FROM "模拟电路与系统"
SORT created ASC
```

## 未完成任务

```dataview
TASK
FROM "模拟电路与系统"
WHERE !completed
```


### 8.4 课程笔记汇总（学生阶段专用）

```markdown
# 模拟电子技术 - 课程笔记汇总

```dataview
TABLE type AS 类型, created AS 日期
FROM #课程/模拟电子技术
SORT created ASC
```

## 九、Graph View（图谱）的用法

### 9.1 期末复习用 Graph View

学期末打开 Graph View，过滤条件：

1. 搜索框中输入 `#课程/模拟电子技术` → 只看这门课的所有笔记
2. 观察哪些节点是**孤立的**（没有箭头连接）——这些笔记缺少链接，可能也没和你的知识体系建立连接
3. 观察哪些节点是**枢纽节点**（很多箭头指向它）——这些是核心概念，确保你真正理解

### 9.2 不要沉迷 Graph View

Obsidian 的图谱看起来很美，但**它是一种回顾工具，不是思考工具**。章末的 A4 纸画图才是真正的思考，Graph View 只是帮你发现「哪些笔记我忘了加链接」。

## 十一、同步与备份

### 方案一：Obsidian Sync（官方付费）

优点：无缝同步，端到端加密。
适合：有多设备需求（宿舍台式机 + 教室笔记本）。

### 方案二：Git + 免费

在仓库根目录初始化一个 git 仓库：

```bash
cd ~/Documents/微电子笔记库
git init
git add .
git commit -m "初始化笔记库"
```

配置 `.gitignore`：

```
.obsidian/workspace.json
.obsidian/workspace-mobile.json
.trash/
```

然后推到 GitHub 私有仓库。每次笔记归档后 commit 一次即可。
```
  # 1. 暂存所有变更
  git add -A

  # 2. 提交（带日期标注）
  git commit -m "2026-08-04 更新"

  # 3. 推送到远程
  git push
```

### 方案三：OneDrive / iCloud

直接把仓库文件夹放在 OneDrive 或 iCloud 目录下。简单但注意：Obsidian 两边同时打开时可能有冲突。

## 十二、极简起步

如果你不想一下子配置这么多，今天只做以下三件事：

1. **建好顶层文件夹**（照 [[库说明]] 的目录表建，不要翻旧稿）
2. **创建五个模板文件**（第四节：概念卡片、公式推导、EDA操作、论文阅读、域总览）
3. **启用「模板」核心插件**：设置 → 核心插件 → 开启「模板」，模板文件夹设为 `Templates/`

其他插件（Excalidraw、Dataview、Latex Suite）按需逐步添加，不要一次性装 20 个插件——你会花更多时间折腾插件而不是记笔记。
