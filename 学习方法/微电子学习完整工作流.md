# 微电子学习完整工作流

> 一份可执行的日常操作指南——从上课第一笔到毕业后检索，每个阶段做什么、用多长时间、产出什么。

---

## 全局节奏

```
每天
  课上：纸笔速记（不停笔，不追求整洁）
  晚上：30 分钟处理（解决问号 + 5句话总结）
           │
           ▼
每周
  周末：1-2 小时归档（筛选纸质精华 → 数字卡片 + 链接）
           │
           ▼
每章
  章末：30 分钟（A4 纸画概念关系图 → 拍照入数字笔记）
           │
           ▼
每学期
  期末：回看概念图 + 卡片，不重翻纸质本和教材
           │
           ▼
跨学期
  学后续课时回头看旧笔记 → 补充"现在才懂"→ 修正旧错误
```

---

## 阶段一：原始捕获

| 项目 | 内容 |
|------|------|
| **时机** | 课上、看书时 |
| **工具** | 普通纸质笔记本（别买贵的） |
| **耗时** | 与课堂同步 |
| **产出** | 布满草稿、问号、箭头的几页纸 |

### 操作规则

```
┌─────────────────────────────────────────┐
│ 左上角写：日期 + 课程 + 章节             │
│                                         │
│ 剩下的随便写——                           │
│                                         │
│ • 老师讲的关键词、公式                   │
│ • 你没听懂的地方（打个大问号，别停）      │
│ • 突然想通的瞬间（用 ⚡ 标记）            │
│ • 随手画的草图                           │
│                                         │
│ 规则：                                   │
│   • 不停笔。听不懂也记。                  │
│   • 字丑没关系。                         │
│   • 这一页只活 24 小时。                  │
│   • 纸质本不追求整洁——它不是作品。        │
└─────────────────────────────────────────┘
```

### 不要做的事

- ❌ 试图当堂整理出漂亮的结构
- ❌ 用尺子画电路图
- ❌ 纠结没听懂的地方（标个问号继续走）
- ❌ 用多色笔搞"笔记系统"（分心）

## 阶段二：当日处理

| 项目 | 内容 |
|------|------|
| **时机** | 当天晚上，必须在 24 小时内 |
| **工具** | 同一支笔，同一本笔记本 |
| **耗时** | 30 分钟/门课 |
| **产出** | 补全的纸质笔记 + 5 句话总结 |

### 操作步骤

```
第一步：解决问号（10 分钟）
  → 翻白天原始笔记里的问号标记
  → 翻教材、问同学、搜资料
  → 在原始笔记旁边用红笔补上答案

第二步：标注重点（5 分钟）
  → 用红笔圈出本节课 TOP 3 核心概念
  → 用红笔划掉"其实不那么重要"的内容

第三步：5 句话总结（15 分钟，合上书写）
  → 这章到底在解决什么问题？
  → 核心方法是什么？（不超过 2 个关键词）
  → 它依赖什么前置知识？
  → 它会被什么后续知识用到？
  → 我第一次学时的误区是？
```

### 为什么必须 24 小时内

艾宾浩斯遗忘曲线：24 小时不处理，忘掉 50-70%。等到周末回头看，你已经读不懂自己写的草稿了。

### 不要做的事

- ❌ 超过 30 分钟还在搞（说明在抄书，不是在处理）
- ❌ 试图当天就做成漂亮的数字笔记（那是周末的事）
- ❌ 跳过总结直接抄书上的定义

## 阶段三：周末归档

| 项目 | 内容 |
|------|------|
| **时机** | 每周末，固定时段 |
| **工具** | 纸质笔记本 + 手机相机 + 数字笔记工具 |
| **耗时** | 1-2 小时/周 |
| **产出** | 数字笔记中的概念卡片、公式卡、对比表、踩坑记录 |

### 筛选标准

```
进入数字笔记的标准（满足任一即可）：

✅ 概念卡片：一个核心概念，3 句话说清楚。每个概念一张卡片。
✅ 公式直觉卡：一个公式 + 参数物理含义 + 典型值代入 + 极限情况检验。
✅ 对比表：两个以上容易混淆的东西放一起比。
✅ 关键推导拍照：10 页草稿只留最关键的 3-5 步。
   拍照插入，标注"这一步为什么是核心"。
✅ 踩坑记录：本周 EDA/实验中犯的错 + 解决方案。

不进入数字笔记的：

❌ 完整的推导过程（留在纸质本里封存即可）
❌ 书上已经有的定义和描述
❌ 例题的完整解答过程
❌ 所有"以后可能会用到"的边角料
```

### 操作步骤

```
1. 翻开本周所有纸质笔记
2. 对照筛选标准，用荧光笔标出"值得数字化"的内容
3. 逐一做成数字笔记卡片（用模板）
4. 给每张新卡片加至少两个 [[双向链接]]：
   ← 链接到前置知识
   → 链接到后续应用
5. 如果某篇旧卡片现在看来太浅，标记 #需要更新
```

### 质量标准

每篇数字笔记必须通过测试：**三个月后回来看，能在 30 秒内把核心要点装回脑子里。** 通不过就压缩重写。

### 不要做的事

- ❌ 把纸质笔记拍照全量导入（垃圾进垃圾出）
- ❌ 花时间调整格式/颜色/字体
- ❌ 让截图替代文字——截图不能搜索

## 阶段四：章末画图

| 项目 | 内容 |
|------|------|
| **时机** | 每学完一章 |
| **工具** | 一张 A4 白纸 + 笔。纯纸笔，不用任何软件 |
| **耗时** | 30 分钟 |
| **产出** | 一张概念关系图（拍照存入数字笔记） |

### 操作步骤

```
1. 在 A4 纸中央写上本章核心主题
2. 从中心画出箭头，连接到子概念
3. 子概念之间画箭头，标注关系
4. 画完问自己：
   • 哪个箭头我还解释不清楚？
   • 哪个概念是我硬塞进去的（其实没真懂）？
5. 把卡住的地方用红笔标出来
6. 手机拍照，存入数字笔记
```

### 示例

```
    [[半导体物理：PN 结]]

       能带图 ──→ 内建电势 Vbi
                    │
                    ├──→ 耗尽区宽度 W
                    │       │
                    │       └──→ 结电容 Cj
                    │
                    └──→ I-V 特性
                            │
                            ├──→ 正向：扩散电流主导
                            └──→ 反向：产生-复合电流主导
```

### 为什么要用纸笔而不是软件

纸让你专注于**概念之间的关系**。用 draw.io 或 Mermaid 会让你分心去调样式、对齐、颜色——这些对理解没有帮助。

### 不要做的事

- ❌ 用绘图软件（分心调样式）
- ❌ 追求美观——这图只需要你自己能看懂
- ❌ 把所有概念都塞进去（只放核心节点）

## 阶段五：跨学期回溯

| 项目 | 内容 |
|------|------|
| **时机** | 学后续课时，发现用到了以前的知识 |
| **工具** | 数字笔记工具 |
| **耗时** | 5-10 分钟/次 |
| **产出** | 旧笔记新增的"补充理解"段落 |

### 触发条件

当你学新课，遇到以下信号时触发回溯：
- "这个我之前学过但我现在讲不清楚"
- "原来那个东西是用在这里的"
- "大二的时候完全没理解这公式的物理意义"

### 操作步骤

```
1. 打开数字笔记中那篇旧笔记
2. 在末尾追加：

   ## 回看补充（20XX年X月，学[[新课名]]时）

   [用新层次的视角重新解释这个知识点]
   [点出当时没理解到的深层原因]
   [建立新课和旧知之间的链接]

3. 如果旧笔记有原则性错误，直接修改原文。
   不要保留"当年青涩的自己"——
   笔记是大脑的外部镜像，大脑更新了，笔记也应该更新。
```

### 实例

```markdown
## 回看补充（大三上，学[[模拟IC设计]]时）

现在才真正理解为什么饱和区对放大有用——
不是因为电流大，而是因为沟道夹断后
Id 对 Vds 不敏感，输出阻抗高，
所以能做高增益。

大二时只记住了 Id 公式，完全没理解"阻抗"的意义。
其实是同一个东西的两种说法——
ro = 1/(λ·Id) 越大 → 增益 gm·ro 越高。
```

## 学期节奏日历

```
第 1-16 周（上课期间）：
  每天做阶段一 + 阶段二
  每周做阶段三
  每章结束做阶段四

第 17-18 周（期末复习）：
  不需要重翻纸质笔记本
  不需要重翻教材
  只看数字笔记中的：
    • 概念卡片（30 秒/张快速过）
    • 概念关系图（章末画的那些）
    • 5 句话总结
  卡住的地方回看完整卡片
  仍有疑问的回到教材

假期 / 下学期：
  学新课触发阶段五
```

## 工具清单

| 用途 | 推荐 | 备选 |
|------|------|------|
| 纸质速记本 | 普通 A5/B5 横线本，10 元以下 | 任何能写字的纸 |
| 纸质整理本 | 同上，可以用另一本 | 也可以和速记本合并 |

| 拍照 | 手机自带相机 | — |
| 画图（章末关系图） | A4 白纸 + 黑笔 + 红笔 | — |

## 唯一底线

如果上面全部只能做一件事，做这个：

> **每天晚上花 15 分钟，合上所有资料，用纸笔默写今天学到的 3 件事。写不出来就说明今天没学。**

其他所有步骤——归档、画图、链接、回溯——都是锦上添花。这件事是底线。
