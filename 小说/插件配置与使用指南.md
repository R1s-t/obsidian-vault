# 小说库插件配置与使用指南

> 本文是小说库的搭建手册。git 部分已由我配置好，插件部分按下面顺序装即可。
> 你的库会写多个小说、彼此可能独立也可能共享，所以整套方案用「`小说`」属性来区分项目，插件配置一次，多本通用。

---

## 0. 已完成（无需再操作）

- ✅ `git init` 完成，分支 `main`
- ✅ `.gitignore` 已写好（忽略 `workspace.json` 和回收站，与你微电子库一致）
- ✅ git 身份已就绪：`Risttt / ris-ttt@outlook.com`

剩余两件事：**① 装插件 ② 建 GitHub 私有库并 push**（见文末）。

## 1. 关键前提：插件是「按库」安装的

你在微电子库已经装了 dataview / quickadd / templater 等，但它们**只存在于微电子库的 `.obsidian` 里**，小说库不会自动拥有。需要到小说库重新装一遍。

装法：`设置 → 第三方插件 → 关闭「安全模式」→ 浏览 → 搜索插件名 → 安装 → 启用`。

| 插件 | 小说库里的用途 |

## 3. 核心属性设计（多小说通用的关键）

**核心思路**：每个笔记都用 `小说` 属性标记属于哪本书。这样无论两本小说是共享设定还是完全独立，Dataview 都能按书筛选，插件也不用重复配置。

### 章节属性

```yaml
---
类型: 章节
小说: 书名1
章节号: 001
标题: 
状态: 草稿        # 草稿 / 修订 / 完成
字数: 0
POV:            # 视角人物
时间线: 
出场人物: []
伏笔埋设: []
伏笔回收: []
---
```

### 人物属性

```yaml
---
类型: 人物
姓名: 
身份: 
年龄: 
阵营: 
登场书: []       # 在哪些书里出现（跨书追踪的关键）
状态: 活跃        # 活跃 / 死亡 / 退场
动机:            # 这个角色想要什么（最重要）
目标: 
弱点: 
关系: []
---
```

### 设定属性

```yaml
---
类型: 设定
分类: 地理        # 地理 / 势力 / 体系 / 编年史
首次出现: 
相关人物: []
相关小说: []
---
```

## 4. Templater 模板（复制即用）

装好 Templater 后，`设置 → Templater → Template folder location` 指向你的模板文件夹，然后在里面新建以下三个文件。

### 章节模板

```markdown
---
类型: 章节
小说: 
章节号: 
标题: 
状态: 草稿
字数: 0
POV: 
时间线: 
出场人物: []
伏笔埋设: []
伏笔回收: []
---

# <% tp.file.title %>

> 本章目标：

## 正文

## 章末检查
- [ ] 字数达标
- [ ] 埋设/回收伏笔已登记到属性
- [ ] 出场人物已在人物卡更新
```

### 人物卡模板

```markdown
---
类型: 人物
姓名: 
身份: 
年龄: 
阵营: 
登场书: []
状态: 活跃
动机: 
目标: 
弱点: 
关系: []
---

# <% tp.file.title %>

> 一句话概括：

## 外貌
## 性格
## 动机与目标
## 关系
## 角色弧线
## 登场记录
```

### 设定模板

```markdown
---
类型: 设定
分类: 
首次出现: 
相关人物: []
相关小说: []
---

# <% tp.file.title %>

## 概述
## 细节
## 关联
```

## 5. QuickAdd 配置（一键新建）

装好 QuickAdd 后，在 `设置 → QuickAdd → Manage Macros` 建两个命令：

### 「新建章节」
- 类型选 **Template**
- 模板选上面的「章节模板」
- 创建位置设为你的章节文件夹
- 文件名格式建议用 `{{VALUE:章节号}}`，这样每次会弹窗让你填章节号，自动生成 `001.md`、`002.md`…

### 「新建人物」
- 类型选 **Template**，模板选「人物卡模板」，位置设为人物文件夹
- 文件名格式用 `{{NAME}}` 或直接手动输入姓名

### 「丢灵感」
- 类型选 **Capture**
- 捕获位置设为 `00-Inbox` 或你的灵感收件箱
- 之后随时按快捷键，把一句话灵感丢进去，事后整理

> 配好后到 `设置 → 快捷键` 给这三个命令各设一个快捷键，写作时就能无感调用。

## 6. Dataview 仪表盘

在任意总览页（比如某本书的首页）放以下查询。**把 `FROM` 换成你自己的章节文件夹路径**，或者删掉 `FROM` 让它全局按 `类型 + 小说` 过滤。

### 某本书的章节进度表

```dataview
TABLE 状态, 字数, POV, 时间线
FROM "你的书稿文件夹"
WHERE 类型 = "章节" AND 小说 = "书名1"
SORT 章节号 ASC
```

### 所有小说的完成度一览

```dataview
TABLE rows.length AS 章节数, sum(rows.字数) AS 总字数
FROM "你的书稿文件夹"
WHERE 类型 = "章节"
GROUP BY 小说
```

### 人物总表（跨书）

```dataview
TABLE 登场书, 状态, 身份
FROM "你的人物文件夹"
WHERE 类型 = "人物"
SORT 姓名 ASC
```

### 埋了但没回收的伏笔（防烂尾关键）

```dataview
TABLE 伏笔埋设, 伏笔回收
FROM "你的书稿文件夹"
WHERE 类型 = "章节" AND 伏笔埋设 AND !伏笔回收
```

## 7. Longform 项目（每本书一个）

1. 装好后，`设置 → Longform → Vault root for projects` 指定你的书稿文件夹
2. 点 Longform 侧边栏图标 → `New Project` → 命名为书名
3. 它会把该项目文件夹下的章节自动列出来，可**拖拽排序**场景/章节
4. 写完后用 **Compile** 把整本书导出成一个 `.md` 手稿文件

> 适合「每本书一个文件夹」的组织方式，跟你多小说的需求正好匹配。

---

## 8. Obsidian Git 自动备份

1. 装好后 `设置 → Obsidian Git`：
   - **Auto commit**：开启，间隔设 `15` 分钟
   - **Auto pull**：如果多设备就开，单设备可关
   - 其余保持默认
2. 每次写完一章，按 `Ctrl+P` → 输入 `Obsidian Git: Push` 推到 GitHub（push 需要手动，或者开启 `Push on backup` 自动推）

---

## 9. 日常写作流（把上面串起来）

1. 有灵感 → 快捷键「丢灵感」→ 进 `00-Inbox`
2. 规划章节 → 「新建章节」→ 填章节号 → 自动生成带属性的空章
3. 写作 → 左下角 Novel Word Count 看字数进度
4. 每章写完 → 更新 `状态/字数/伏笔` 属性 → 章末检查打勾
5. 收工 → `Ctrl+P → Obsidian Git: Push` 备份到 GitHub
6. 阶段性 → 打开仪表盘看章节进度和未回收伏笔，调整大纲

---

## 10. 连接 GitHub（最后一步）

在 GitHub 新建一个 **Private** 空仓库（名字随意，如 `novel-vault`），然后在小说库目录下执行：

```bash
cd ~/Documents/NovelVault
git add -A
git commit -m "初始化小说库"
git remote add origin https://github.com/你的用户名/novel-vault.git
git push -u origin main
```

> 首次 push 会弹 GitHub 登录窗口，登录一次即可。以后 Obsidian Git 插件的 Push 就是点一下就推。
