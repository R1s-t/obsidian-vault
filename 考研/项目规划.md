# 项目规划（2026-2028）

> 目标：**2028 届考研，初试 2027-12-25/26**，报考华五集成电路 / 微电子。
> 核心判断：项目是「过线之后的区分度」（复试 20–25%），不是「过线的替代品」（初试 60–70%）。
> 全部严格单人 · 不做板级（不画 PCB、不焊板、不跑单片机）· 不碰水赛。

配套笔记：[[微电子/90-项目实战/微项目练习清单|微项目练习清单]] · [[微电子学习资源与刷题工具|学习资源与刷题工具]] · [[集创赛/00-总览|集创赛总览]]

## 一、约束与目标

| 维度 | 已定 |
|---|---|
| 身份 | 厦门大学 微电子科学与工程，大三上（2026-11） |
| 目标院校 | 华五（清北复交浙科南），微电子 / 集成电路 |
| 主方向 | 数字前端 RTL → 处理器 / AI 加速器 |
| 辅方向 | EDA（仿真器、形式验证、开源工具链）+ 验证 |
| 模拟定位 | 只做 2 个，建立器件与寄生直觉，不深入 |
| 硬红线 | 单人；不画 PCB / 不焊板；**2027-09-06 起无条件停项目转初试** |
| 工时口径 | 学期 17–20h/周，假期 40–45h/周 |
| 预算 | 约 1000–1300 元（OSPP 可倒赚 3500–10000） |

**为什么不做板级**：蓝桥杯电子赛 6 个赛道里，单片机 / 嵌入式 / 物联网 / 5G 全是板级；「EDA 设计与开发」赛道实际是用嘉立创 EDA 画 PCB（符号、封装、原理图、导入库），名字极具误导性。真正的芯片级入口只有集创赛、一生一芯、OSPP、TinyTapeout 四个。

## 八、AI 使用分工

| 环节 | 交给 AI | 必须自己做 |
|---|---|---|
| 环境配置与报错 | 90%（但错误原因要读懂） | 判断是不是真的修好了 |
| Verilog 样板代码 | 生成 | 微架构决策、时序取舍 |
| testbench | 重复用例 | 覆盖率模型、边界定义 |
| 汇编器 / C++ 骨架 | 生成 | 指令编码表逐条核对 |
| 论文与手册 | 摘要 | ISA 关键章节精读 |
| 模拟版图 | 不交 | **全部自己做（靠手感）** |
| 日志分析 | 提取与定位 | 看波形下结论 |
| 报告初稿 | 生成 | 结论与数据 |

每个项目的 README 加一节「AI 使用说明」：写清哪部分由 AI 生成、你改了哪里、你怎么验证的。面试时这比「我手写了 5000 行」值钱。

## 十、复试叙事

**30 秒版**：

> 我主要做数字设计和 EDA。我写了一个 RISC-V CPU，做到能跑起来、能上板；为了搞懂工具在做什么，我自己写了一个 Verilog 仿真器来跑它；用形式验证证明了流水线不会死锁、ALU 符合 ISA 定义；最后用 OpenLane 做完后端，看了 PPA。我还做了两个模拟项目，是为了理解版图寄生对时序的影响。我的一份设计也送去了流片。

**四个能撑 5 分钟追问的点**：

1. 为什么自己写仿真器 ——「Verilator 的调度和教科书讲的事件驱动不一样，自己写一遍才明白周期驱动快在哪、慢在哪。」
2. 形式验证证了什么 ——「ALU 全输入空间等价于 ISA 定义；流水线在任何输入序列下不会死锁。」
3. 后端最大收获 ——「同一份 RTL 换约束 PPA 差 30%，设计和实现是两件事。」
4. 模拟学到什么 ——「版图寄生让运放相位裕度掉了 15 度，前仿是骗人的。」

**讲项目用「问题—方案—数据」三段**：❌「我做了一个五级流水 RISC-V CPU」／✅「跑到 100MHz。load-use 冒险先用 stall，性能损失 30%；改成 forwarding + 一条 bubble，降到 5%。这是前后 CPI 对比和综合报告。」

### 只有 8 小时的兜底版

做 1 → 2 → 3 → 4 就跑（注册 + 环境 + hello world）。加法器和仓库顺延到 W2，不算失败——**环境没过，后面全卡**，这才是必须本周拿下的。

### 卡壳预案

- **装环境超过 5h**：立刻停，改用 [EDA Playground](https://www.edaplayground.com) 在线跑 Verilog 交差；本机环境挪到下周末，别让装环境吃掉整个 W1。
- **一生一芯注册卡住**：发邮件问官方，别自己猜流程；这一项拖一周，预学习就整体后移一周。
- **WSL2 装不上（虚拟化被关）**：进 BIOS 开 VT-x / SVM，或先用 Windows 版 Verilator + Icarus，GitHub Actions 里跑 Verilator 也行。
