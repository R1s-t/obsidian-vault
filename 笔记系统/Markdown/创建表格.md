***打完源代码后要在首行首位回车
（一）默认居左：在每个单元格之间添加 | 作为纵向分隔符，在页眉下方添加一行短划线，分隔符行中的每个单元格必须使用三个或多个短划线， | 不需要垂直对齐


| Option | Description                         |
| ------ | ----------------------------------- |
| data   | path to date files                  |
| engine | handlebars is the default           |
| ext    | extension to be used for dest files |
（二）列表居中（Center text in a column)
若要将文本置于列的中心，请在页眉下的行中的短划线的左右两测添加冒号：

| Option |             Descriotion             |
| :----: | :---------------------------------: |
|  data  |         path to data files          |
| engine |      Handlebars is the default      |
|  ext   | extension to be used for dest files |
(三)列表居右（Right-align the text in a column)
若要将列中的文本右对齐，请在标题下方行中虚线的右侧添加冒号。

| Option |                         Description |
| -----: | ----------------------------------: |
|   data |                  path to data files |
| engine |           Handlebars is the default |
|    ext | extension to be used for dest files |
