# 实验一 不同 W/L 比 MOS 管性能测试 —— 数据表

## 目标

把 n33（NMOS）与 p33（PMOS）在 V_DS = ±1.5 V、V_ov = 0.2 V 下的 vth、i_d、g_m、g_ds 逐个尺寸量出来，边量边填，量完直接出报告。

## 环境

- 工具：ADE L + Spectre（ic618 虚拟机）
- PDK：`smic13mmrf_1233`，模型库 `ms013_io33_v2p6_7p_spe.lib`，section `tt`
- cell：`nmos_wl`（n33）/ `pmos_wl`（p33）；Project Directory：`~/simulation/wl`
- 变量：`w`、`L`、`VGS`、`VDS`

## 填写规则

- V_GS* 是**偏置点**不是变量：先查 vth，再令 `VGS = vth + 0.2`（PMOS 为 `vth − 0.2`，取负值），把 dc 的 Start 与 Stop 都设成这个值跑单点。
- 单位口径：I_D 用 µA、g_m 与 g_ds 用 µS、r_o = 1/g_ds 用 kΩ（g_ds 若显示 mS 先乘 1000）。
- r_o 除了 1/g_ds，还要用输出特性曲线算一遍：`r_o = (1.8 − 1.2) / (I_D(1.8) − I_D(1.2))`，两者对照写进报告。
- PMOS 的 i_d、vth 读出来是负数，表里**一律填绝对值**，V_DS 记 −1.5。
- g_m/I_D 自检：V_ov = 0.2 V 时应在 7~10 V⁻¹（理想 2/V_ov = 10，短沟道会低一些）；算出来是 0.x 或上百就是单位错了。
