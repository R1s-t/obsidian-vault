# 数据类型
## 整数
- 任意大小，没有大小限制
- 包括负整数
- 表示方法与数学写法一样
- 十六进制有时比较方便，表示方法：`0x`前缀，0-9，a-f表示
- 对于很大的数，允许在数字中间用`_`分隔，包括十六进制
- 整数运算永远精确，包括除法
- `//`称为地板除，两个整数相除结果仍然是整数%%只取结果的整数部分%%
- `%`余数运算，如`10 % 3`，结果为`1`
## 浮点数
- 可以用数学写法如`1.23`，`3.14`，`-9.01`
- 对于很大或很小的浮点数，必须用科学计数法，把10用e表示，如$1.23\times10^9$，就是`1.32e9`,或者`12.3e8`，$0.000012$，就是`1.2e-5`
- 浮点数运算可能有四舍五入的误差
- `/`除法运算结果是浮点数
- 没有大小限制，但是超出一定范围会直接表示为`inf`（无限大）
## 字符串
- 用单引号`'`或双引号`"`括起来的任意文本，注意字符串一旦出现，必然伴随引号
- 转义字符`\`
	- 字符串内部包含引号时用`\`
	- `\n`表示换行
	- `\t`表示制表符
	- `\`本身也要转义，`\\`表示`\`
	- ==转义字符本身就是字符串==
- 有多个换行时，用`\n`写在一行不好阅读，可以用`'''...'''`的格式表示有多行内容
- 当提示符变为`...`时提示接着上一行输入
- 多行字符串还可以在前面加上`r`
	- `r`的作用是让字符串变为原始字符串，`\n`不转义
	- `'''...'''`内部的`\n`也会单独作用为换行，`r`可使其不转义
## 布尔值
```
True
False
```
- 可以用`and\or\not`运算
	- `and`为与运算
	- `or`为或运算
	- `not`为非运算，是单目运算符
- 常用于条件判断
## 空值
```
None
```
- 不能理解为`0`，`0`是有意义的
- 是一个特殊的空值
# 变量
- 变量可以是任意数据类型
- 变量用变量名表示，变量名是大小写英文、数字和`-`的组合，不能用数字开头
- 等号` = `是赋值语句，可以把任意数据类型赋值给变量，同一变量可以反复赋值，可以是不同类型的变量
- 动态语言：变量本身类型不固定的语言
- 静态语言：定义变量时必须指定变量类型，若赋值时类型不匹配则报错
# 常量
- 即不能变的变量
- 通常用全部大写的变量名表示常量
- 实际上仍然是一个变量，还是可以改变
