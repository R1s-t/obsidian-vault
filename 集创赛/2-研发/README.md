# 研发目录说明

赛道定下来后，在本目录下按需创建子目录，**不要一次建全**。常见分支：

- `电路设计/` —— 模拟/射频电路、模块 schematic
- `RTL设计/` —— 数字/SoC 的 RTL 源码
- `验证/` —— testbench、断言、覆盖率
- `版图/` —— 版图、DRC/LVS
- `仿真/` —— 仿真设置、结果、波形
- `综合与时序/` —— 综合脚本、约束、时序报告
- `测试与调试/` —— 测试方案、仪器记录、调试日志
- `工具与环境/` —— EDA 脚本、环境配置、版本管理

## 约定

- 每个子目录放一个 `README.md`，说明用途、当前状态和负责人。
- 代码/工程文件可入库；大文件（波形、比特流、安装包、原始数据集）走网盘或单独存储，不塞进 vault。
- 实验过程记到 [[集创赛/2-研发/实验记录|实验记录]]。
