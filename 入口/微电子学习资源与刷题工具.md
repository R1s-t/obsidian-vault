# 微电子学习资源与刷题工具

> 配套 [[考研/项目规划|项目规划]]。
> 用法：**不要按顺序看完**。每个阶段只取当下要用的那一条，学完立刻动手，动手卡住再回来查。

## 一、体系课（系统学，不是碎片）

| 课程 | 内容 | 什么时候用 |
|---|---|---|
| [一生一芯预学习](https://ysyx.oscc.cc) | 数字电路 → Verilog → RISC-V → 计算机系统 | **P0 主线**，官方清单照做 |
| [Nand2Tetris](https://www.nand2tetris.org) | 从 NAND 门一路造到 CPU 和汇编器 | 想搞懂「仿真器/汇编器」到底在干什么时 |
| [MIT 6.004](https://ocw.mit.edu) Computation Structures | 数字逻辑 + 体系结构 | 数字电路基础不牢时补 |
| [Berkeley CS61C](https://cs61c.org) | 计算机体系结构（RISC-V 版） | 做 CPU 之前 |
| 南京大学 计算机系统基础（PA） | 一个实验贯穿到 OS | 想练「大工程」手感 |
| 中科大 计算机体系结构（B 站） | 流水线、Cache、乱序 | P1 做五级流水时 |
| B 站搜「一生一芯」 | 官方讲座录像 | 卡在 A 阶段时 |

## 二、Verilog / RTL

- **[HDLBits](https://hdlbits.01xz.net/wiki/Main_Page)** —— 刷题首选。170+ 题，从门电路到状态机到 CPU 片段，全部在线判题，不用装环境。**目标：P0 刷完 50 题。**
- [ASIC-World](https://www.asic-world.com) —— 语法速查 + 可运行例子。
- [EDA Playground](https://www.edaplayground.com) —— 在线跑 Verilog / SystemVerilog / UVM，装环境失败时的救命通道。
- [Sunburst Design 论文库](https://www.sunburst-design.com/papers/) —— Cliff Cummings 的 CDC 与编码规范，**CDC 的圣经**。配合 A2 异步 FIFO 读。
- [ChipVerify](https://www.chipverify.com) —— 验证概念 + SystemVerilog + UVM 入门。

## 三、RISC-V

- [RISC-V 官方规范](https://riscv.org/technical/specifications/) · [riscv-isa-manual](https://github.com/riscv/riscv-isa-manual) —— 只精读 RV32I 那几章，别通读。
- [riscv-tests](https://github.com/riscv-software-src/riscv-tests) —— **你的 CPU 必须过这套测试**，这是 A 阶段的验收标准之一。
- [香山 OpenXiangShan](https://github.com/OpenXiangShan/XiangShan) —— 国产高性能 RISC-V 核，读它的文档和设计博客，OSPP 的目标社区之一。
- 《RISC-V 手册》（RISC-V Reader 中文版）—— 免费 PDF，一晚上能翻完，建立整体图景。

## 四、形式验证

- [SymbiYosys 文档](https://yosyshq.readthedocs.io) —— sby 的配置写法，`[tasks]` / `[options]` 两节看完够了。
- [Yosys 手册](https://yosyshq.readthedocs.io) —— 只用 `read_verilog` / `prep` / `smtbmc` 几个命令，别陷进去。
- [ZipCPU 博客](https://zipcpu.com) —— Dan Gisselquist 写的 formal 实战系列，**学 formal 最好的免费材料**。
- 《Formal Verification: An Essential Toolkit》（Erik Seligman）—— 讲「该证什么」，不讲课怎么跑。

## 六、模拟

- Razavi《模拟 CMOS 集成电路设计》—— 只读运放、电流镜、带隙三章；B 站有 UCLA 网课录像。
- 复旦模拟 IC 课程（B 站）—— 中文，讲得细。
- 《Analysis and Design of Analog Integrated Circuits》（Gray & Meyer）—— 查手册用，别通读。
- KLayout + Sky130 做版图练习；DRC / LVS 用 Magic + netgen。

## 七、体系结构进阶

- 《Computer Organization and Design》RISC-V 版（Patterson & Hennessy）—— 做 CPU 时的案头书。
- 《Computer Architecture: A Quantitative Approach》—— 只在写 GEMM 加速器、算 roofline 时翻对应章节。
- 《硬件架构的艺术》—— 讲时钟、复位、CDC 的工程实践，薄且实用。

## 八、刷题与自测工具

| 工具 | 练什么 | 目标量 |
|---|---|---|
| [HDLBits](https://hdlbits.01xz.net/wiki/Main_Page) | Verilog 语法与设计 | 50 题（P0） |
| [EDA Playground](https://www.edaplayground.com) | 在线仿真、UVM 例子 | 按需 |
| [LeetCode 中国站](https://leetcode.cn) | C++ 手感（EDA 线要用） | 60 题 |
| [Exercism C++ track](https://exercism.org) | C++ 工程习惯 | 10 题 |
| [牛客网 · 数字 IC / 硬件岗](https://www.nowcoder.com) | 秋招笔试真题 | 200 题（P5 复试前） |
| [riscv-tests](https://github.com/riscv-software-src/riscv-tests) | ISA 一致性 | 全过 |
| ChipVerify Quiz | 验证概念自测 | 按需 |

**刷题的正确姿势**：HDLBits 不是刷数量，每道题做完问自己一句「这道题对应的电路长什么样、综合出来多少 LUT」。牛客的数字 IC 题放到 P5，别提前刷——那时才有语境。
