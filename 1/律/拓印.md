# 拓印

> 用「面」（平面或曲面）去截 [[原本|律]] 这个三维物体，截面遗留的图案，就是拓片。用材料记录原本的某个状态，不同的角度、深度，以及动态原本的拓印时机，都决定拓印结果。

## 核心模型

- 律 = 三维物体。
- 拓印 = 在律上取一个原点 O，以（角度，深度）确定一个平面去截它；平面与物体相交，截面遗留的图案就是拓印结果。

## 五个参数

| 参数 | 决定什么 | 备注 |
|---|---|---|
| 锚点 | 原点选在哪 | 拓印机负责锚定 |
| 角度 | 平面的朝向 | 类角坐标方向 |
| 深度 | 平面离原点的距离 | 类半径 |
| 时机 | 截取的瞬间 | 仅动态律需要 |
| 材料形状 | 平面 / 曲面 | 平拓 / 曲拓 |

## 拓印机

- 职责：锚定原点 + 拨角度 + 拨深度。本质 = 一台带夹具的三坐标测量机。
- **精度分两层**（互相独立）：
  - 锚定精度：钉不钉得住、漂不漂、抖不抖。
  - 定位精度：角度、深度拨得准不准。
- 低阶拓印机输在定位，高阶输在锚定。

## 静态律 vs 动态律

- **静态律**：角度 + 深度定了，截面就定了，无需时机。
- **动态律**：律在变，同角度同深度，不同时刻截面不同，需锁时机。

引申出两派：

- **工拓**（对静律）：可重复、求精度，如工程师。
- **猎拓**（对动律）：一次性、求时机，如狙击手——难在「锚不住」一个在动的律。

## 平面拓 vs 曲面拓

- **平拓**：平面截律，得平面截面。入门。
- **曲拓（全形拓）**：曲面截律，得曲面截面。大师。对应金石学里的碑拓（平）与全形拓（曲）。
- 一张曲面 = 一族平面（曲面上点到原点距离处处不同），信息量远超单张平面。

曲面分两档：

- **可展曲面**（柱面/锥面）：多信息 + 可零畸变展平 → 工拓进阶主流。
- **不可展曲面**（球面等）：信息最多，但展平必畸变 → 巅峰/禁忌。

> [!note] 高斯绝妙定理
> 曲率是内蕴不变量，真正弯曲的曲面，数学上不可能零畸变地摊到平面。

## 拓印必损

两条「损」：

1. **截面之损**：三维律 → 二维截面，丢掉第三维。
2. **展平之损**：曲面拓片 → 平面纸，必畸变（除非律本身无曲率）。

> [!warning]
> 无损拓印在数学上不可能——除了主角（二维律无曲率）。

## 翻拓与代际衰减

唯一律服务全世界的方式：**拓片可以被「翻拓」**（复印复印件）。

- 律 = 原稿，拓印 = 复印，翻拓 = 复印复印件，越来越糊。

代际：**初拓**（律本直拓，最真）→ **翻拓** → **再翻** → **废拓**（只剩形，没有神）。

- 能效：同样的力，初拓效果翻倍，废拓一半浪费。
