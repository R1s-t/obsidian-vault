## 二、为什么不再建子目录

原来是按「库」的思路设计的：进度一科一个文件、错题一科一个台账、真题一科一个日志、模板五个。实际用下来维护成本远大于收益——每科都要建、要填、要更新 `progress` 数字，而真正有用的信息（今天做了什么、哪道题不会）本来就在日记和纸上。

所以砍掉骨架，只留四件事：**倒计时、总规划、关键日期、入口**。
