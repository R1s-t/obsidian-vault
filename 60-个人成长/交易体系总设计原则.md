| 马克斯（周期定位）vs 马尔基尔（择时无效） | **只在极端位置择时：** 平时不择时（默认满仓优质股），但在复合情绪指标>2σ时做结构性调整。马克斯50年只做了4-5次重大周期判断 |

## 统一投资哲学

> **核心信念：** 在安全边际保护下，以合理价格买入优质企业，长期持有让复利工作。利用市场极端情绪作为唯一的进出场加速器。永远不冒会出局的风险。

### 五大支柱

1. **质量优先**（巴芒） — 好企业第一，好价格第二
2. **安全边际**（格雷厄姆） — 买价低于内在价值至少30%
3. **非对称押注**（塔勒布） — 上行大、下行有限；不做可能导致毁灭的事
4. **复利时间**（西格尔/豪泽尔） — 15年+持有期，股票比债券更安全
5. **逆向气质**（邓普顿/施韦德/马克斯） — 在最大悲观点买入，在最大乐观点卖出

### 关于预测的根本立场

> **"最重要的不是预测未来，而是知道如何在每个时点对可用信息做出恰当响应。"** ——达利欧

系统是**反应式**的，不是**预测式**的。它检测当前状态（估值水平、情绪极端、质量变化、体制特征），然后按照预设规则行动——不做关于"接下来会发生什么"的赌注。

## 第二层：估值定价

### 内在价值计算（三方法取保守值）

```python
# 方法A：格雷厄姆数
graham_number = sqrt(22.5 * normalized_eps * tangible_book_per_share)

# 方法B：所有者盈余DCF
owner_earnings = reported_earnings + depreciation - avg_maintenance_capex_5yr
intrinsic_dcf = dcf(owner_earnings, growth=conservative_growth, years=10, 
                     terminal_growth=0.02, discount_rate=risk_free + 0.05)

# 方法C：$1测试
value_creation_ratio = market_cap_change_5yr / cumulative_retained_earnings_5yr
# >1 = 管理层在用留存收益创造价值

# 取三者最保守值
intrinsic_value = min(graham_number, intrinsic_dcf)
# 若value_creation_ratio < 1 → 额外打8折
```

### 反身性检测（索罗斯）

```python
def detect_reflexive_regime():
    """
    检测市场是否处于"远离均衡态"
    """
    # 1. 股价与基本面脱离程度
    price_fundamental_divergence = abs(pe_current - pe_5yr_median) / pe_5yr_median
    
    # 2. 10%跌势是被买入还是引发抛售？
    dip_buying_strength = avg_return_after_5pct_drops_6m
    
    # 3. 公司是否在用股价作为工具？
    share_issuance_intensity = net_equity_issuance / market_cap
    
    # 4. 是否存在"这次不一样"的主流叙事？
    narrative_intensity = count_this_time_different_mentions_media
    
    if all indicators showing extreme readings:
        return "far_from_equilibrium"  # 信号远超均值回归策略
    else:
        return "near_equilibrium"
```

## 第四层：风险管理

### A. 杠铃结构（塔勒布）

```
85-90%: 极安全资产
  ├── 高质量企业（巴芒标准），无杠杆
  ├── 国债/高等级债
  └── 现金（15%底限——不是拖累，是战略期权）

10-15%: 高凸性投机
  ├── 深度价值/净净股（格老NCAV）
  └── 危机中的特殊机会
```

### B. 仓位约束

```yaml
portfolio_constraints:
  max_positions: 15                 # 巴芒：5-15
  top3_weight_min: 0.50             # 最好3只占50%+
  single_stock_max: 0.25            # 默认单只≤25%
  single_stock_ultimate: 0.40       # 最高确信度≤40%（巴1965年规则）
  single_sector_max: 0.40           # 单一行业≤40%
  cash_min: 0.15                    # 永远≥15%现金
  leverage: 0                       # 不使用杠杆（塔勒布+巴菲特+芒格共识）
  
  sell_discipline:
    hard_stop_peak_drawdown: 0.20   # 索罗斯：从峰值-20%硬止损
```

### C. 毁灭风险防火墙

```
1. 无杠杆 → 无强制平仓
2. 单只≤25%/40% → 任何单一事件无法毁灭
3. 现金≥15% → 永远有干火药
4. 多国多行业 → 单一国家/行业事件不致命
5. 杠铃结构 → 90%本金在黑天鹅中存活
```

## 第五层：执行纪律

### 决策流程（芒格双轨+魔鬼代言人）

```
决策 = 理性分析 + 偏误检查 + 魔鬼代言人 + 冷静期

1. 双轨分析
   轨1: 理性上什么因素支配这个决策？
   轨2: 什么潜意识偏误可能在影响我？

2. 魔鬼代言人审查
   强制写出：这个投资会怎么让我永久损失资金？
   列出所有失败模式。有回答不了的→不投。

3. 24-48小时冷静期
   任何交易决定做出后，至少等24小时才能执行。

4. 决策日志
   记录：论据、情绪状态、预期时间维度、出错了会是什么原因
   每季度回顾校准
```

### 心理偏误清单（芒格25条中最重要的）

| 偏误 | 表现 | 系统防御 |
|------|------|---------|
| 激励超级反应 | 相信有利益冲突的人的建议 | 排除所有券商/分析师评级 |
| 确认偏误 | 只看支持自己判断的证据 | 魔鬼代言人强制写反面论据 |
| 损失厌恶 | 亏损时不肯卖 | 硬止损规则+索罗斯20%线 |
| 社会认同 | 大家都在买所以我也买 | 情绪指标用逆向信号 |
| 过度乐观 | 高估成功概率 | 要求保守假设，概率思维 |
| 简单联想 | 因为上次赢了所以觉得这次也会赢 | 检查每次成功的运气成分 |
| 可得性偏差 | 过度关注头条新闻 | 用预设清单，关注不在新闻里的东西 |
| 权威误导 | 信"专家"的市场判断 | 自己做功课 |

## 一个最核心的原则

> **"投资者最重要的品质是气质，不是智力。"** ——巴菲特
>
> **"我最重要的是不是预测未来，而是知道如何在每个时点对可用信息做出恰当响应。"** ——达利欧
>
> **"只知道问题和只知道答案一样危险。最难的回答是'我不知道'。"** ——施韦德

**这个交易体系的目的：不是预测明天涨跌，而是在任何市场环境中——**
- 知道自己持有什么（质量）
- 知道自己付了什么价格（安全边际）
- 知道自己站在周期的哪里（极端位置）
- 知道最坏情况下会不会出局（杠铃+无杠杆）
- 知道自己的判断可能错在哪里（魔鬼代言人+决策日志）
- **——然后用时间去等待复利完成它的工作。**
