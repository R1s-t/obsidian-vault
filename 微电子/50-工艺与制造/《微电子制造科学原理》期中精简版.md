## 记忆总纲

### 一条主线

衬底制备 → 清洗 → 氧化／隔离 → 光刻 → 刻蚀

四个万能问法：加什么，沉积／氧化／注入；去掉什么，刻蚀／清洗／CMP；印什么图案，光刻＋刻蚀；怎么保证一致，量测／终点／均匀性／热预算。

### 流程箭头

- 晶圆生长：熔体 → 籽晶接触 → 拉或推 → 界面推进 → 单晶
- RCA：SPM → APM → HPM → DHF → DIW → IPA
- IMAC：O₃ 水 → DHF/HCl → O₃+HCl → O₃ 干燥
- 光刻八步：预处理 → 匀胶 → 软烘 → 对准曝光 → PEB → 显影 → 坚膜 → 检测
- SAQP：硬掩膜 → 芯轴 → 侧墙 → 回刻 → 去芯轴 → 二次侧墙 → 刻目标层
- Bosch：SF₆ 刻 → C₄F₈ 钝 → 重复
- ALE：改性层 → 低能 Ar⁺ 去除 → 重复

### 口诀

- 单晶生长：越难熔、越易挥发、越难长 → 越靠「容器／气流」兜住。其余口诀如 S-P-H-F、光刻八步、刻蚀气体，已在各章「一页速记」下方。

### 数字一页

| 类别 | 数值 |
|---|---|
| 温度 | 熔硅 1420｜SiC 1500–2500｜Ga 800｜GaN 反应 1000–1100 ℃ |
| 光刻温度 | 脱水 150–200｜软烘 90–110｜PEB 110–130｜坚膜 100–130 ℃ |
| 波长 | g 436｜i 365｜KrF 248｜ArF 193｜EUV 13.5 nm |
| 光刻系数 | k₁ 极限 0.25，量产 0.3–0.35｜浸没 n=1.44、NA 1.35｜2.38% TMAH |

| 清洗 | O₃ 1–2 ppm｜DHF/HPM/APM 步间 DIW |

### 对比速查

- RCA vs IMAC：RCA 靠化学液序 S-P-H-F；IMAC 靠 O₃ 氧化成膜＋稀酸，全程少用浓液。
- BARC vs DARC：有机旋涂吸收 vs 无机 SiON 干涉相消，后者兼硬掩膜。
- RIE vs ICP vs ALE：鞘层轰击各向异性 vs 高密度低气压 vs 自限制原子层。
- 湿法 vs 干法：各向同性、快、便宜 vs 各向异性、可控形貌、需真空。

## 1、半导体晶圆制备

### 一页速记

| 材料 | 方法 | 一句话原理 | 关键温度 |
|---|---|---|---|
| Si | CZ 直拉 | 籽晶上提，熔体薄膜冷却，晶向延续 | 熔硅约 1420 ℃ |
| GaAs | VB 垂直布里奇曼 | 密闭安瓿防 As 挥发，安瓿相对下移 | 上热下冷，固定温场 |
| SiC | HT-CVD | 高温区生成前驱物，气流带到籽晶端沉积 | 1500–2500 ℃ |
| GaN | HVPE | GaCl 与 NH₃ 反应，GaN 沉积 | Ga 800 ℃，反应 1000–1100 ℃ |
| Ga₂O₃ | EFG 导模 | 毛细供料成膜，按模具顶温度梯度结晶 | 近净成形 |

1. ***直拉法（或CZ法）制备硅单晶的原理***

    关键词：籽晶上提｜表面张力带液膜｜晶向延续｜V/G 控界面｜k<1 尾部富集

    籽晶接触熔体后缓慢上提，表面张力带起一层熔体薄膜并冷却；晶向由籽晶延续到新晶体。靠拉速与温度梯度之比 V/G控界面，k<1 的杂质向尾部富集。

2. ***垂直布里奇曼法（VB法）制备砷化镓单晶的原理***

    关键词：密封防 As 挥发｜上热下冷｜安瓿相对下移｜界面自下而上

    密闭石英安瓿防 As 挥发；加热区固定、上热下冷形成温度梯度，驱动安瓿相对下移，凝固界面自下而上推进，得到 GaAs 单晶。[^1]

3. ***高温化学气相沉积法（HT-CVD法）制备碳化硅单晶的原理***

    关键词：1500–2500 ℃｜SiH₄＋乙烷/丙烷｜高温生成前驱物｜气流带到低温籽晶

    1500–2500 ℃ 通入 SiH₄ 与乙烷/丙烷或 H₂；高温区先生成 SiC 前驱物，再由气流带到低温区籽晶端沉积成单晶。

4. ***氢化物气相外延法（HVPE法）制备氮化镓单晶的原理***

    关键词：Ga 800 ℃｜HCl→GaCl｜NH₃ 作 N 源｜1000–1100 ℃｜无同质衬底

    Ga 熔体加热到 800 ℃，用 N₂/H₂ 稀释的 HCl 流过其上方生成 GaCl 作 Ga 源；GaCl 与 NH₃ 作 N 源，在 1000–1100 ℃ 反应，GaN 沉积在衬底上。

5. ***导模法（边缘限定薄膜供料生长法）制备氧化镓单晶的原理***

    关键词：毛细狭缝｜模具顶面成膜｜顶温梯度｜形状由模具定

    带毛细狭缝的耐熔金属模具浸入 Ga₂O₃ 熔体，熔体经毛细作用升到模具顶面成薄膜；籽晶接触薄膜，按模具顶温度梯度结晶，形状由模具限定。

## 2、晶圆污染和清洗

### 一页速记

| 目的 | RCA | IMAC |
|---|---|---|
| 去有机物 | SPM／SC-3 | O₃/DI 水氧化 |
| 去颗粒 | APM／SC-1＋兆声，底切 | DHF＋HCl＋兆声 |
| 去金属 | HPM／SC-2，可加 EDTA | O₃＋稀 HCl，防二次污染 |
| 去氧化层 | DHF 溶解 | DHF |
| 干燥 | 甩干＋IPA 蒸汽 | O₃ 气相干燥并成膜 |

口诀：*S-P-H-F*，即硫酸→氨水→盐酸→氢氟酸，每步之间用 DI 水冲洗。

1. ***晶圆上需要清洗去除的污染（物）***

    关键词：颗粒｜金属离子｜有机物｜自然氧化层｜静电荷 ESD

    五类：颗粒、金属离子、有机物、自然氧化层、静电荷 ESD。

2. ***RCA清洗顺序和原理***

    关键词：S-P-H-F｜APM 兆声底切｜HPM 络合＋EDTA｜DHF 溶氧化层｜步间 DIW｜IPA 甩干

    ①SPM，SC-3，硫酸＋双氧水，去有机；②APM，SC-1，氨水＋双氧水，加兆声底切颗粒；③HPM，SC-2，盐酸＋双氧水，络合金属，加 EDTA 防再沉积；④DHF 溶氧化层；步间 DI 水冲洗；⑤甩干＋IPA 蒸汽干燥。

3. ***稀释化学法原理***

    关键词：颗粒与硅同号电荷｜静电屏蔽｜防再吸附

    稀释 APM/HPM 与 DHF 配兆声波后，颗粒与硅表面带同种电荷，形成静电屏蔽，防止已洗下的颗粒再吸附回晶圆。

4. ***IMAC清洗顺序和原理***

    关键词：O₃ 水氧化成膜｜DHF＋HCl＋兆声｜O₃＋稀 HCl 防二次污染｜O₃ 干燥

    ①含 1–2 ppm O₃ 的 DI 水把有机物氧化为 CO₂、H₂O，并长出致密氧化膜；②DHF＋稀 HCl＋兆声，底切去颗粒、络合去金属；③O₃＋稀 HCl＋兆声，防金属二次污染；④O₃ 气相干燥成膜。

5. ***无水氢氟酸/乙醇（AHF/Ethanol）清洗顺序和原理***

    关键词：低压气相｜乙醇溶有机｜HF＋SiO₂→SiF₄↑｜深槽｜可加 HCl

    低压腔内通 AHF/乙醇混合蒸汽：乙醇溶有机物成挥发小分子，HF 与 SiO₂ 生成 SiF₄ 气体抽走；适合深沟槽与堆叠结构，可加 HCl 增强去金属。

6. ***等离子体清洗原理***

    关键词：O₂ 放电｜有机物氧化成挥发气｜抽走

    O₂ 在电场下成等离子体，把光刻胶等有机物氧化成可挥发气体，由抽气系统排出。

7. ***常用的污染物检测技术***

    关键词：TXRF 查 S–U｜SIMS 查 H–U 含同位素

    ①TXRF，全反射 X 射线荧光，照晶圆测荧光峰，查 S–U 元素；②SIMS，二次离子质谱，离子束溅射出二次离子，查 H–U 及同位素。

## 3、光刻（光刻岗位常见面试题）

### 一页速记

| 项目 | 数值/公式 |
|---|---|
| 曝光波长 | g 436／i 365／KrF 248／ArF 193／EUV 13.5 nm |
| 分辨率 | R=k₁λ/NA；焦深 DOF=k₂λ/NA²；k₁ 极限 0.25，量产 0.3–0.35 |
| 浸没 | n=1.44，NA 可达 1.35 |
| 胶厚 | t∝1/√ω，转速越大越薄 |
| 温度 | 脱水 150–200／软烘 90–110／PEB 110–130／坚膜 100–130 ℃ |
| 显影 | 2.38% TMAH，puddle 静止覆液 |

顺序口诀：*预处理→匀胶→软烘→对准曝光→PEB→显影→坚膜→检测*。

1. ***什么是关键尺寸、分辨率、数值孔径和overlay？***

    关键词：CD 最小线宽｜R=k₁λ/NA｜NA=n·sinθ｜overlay 约线宽 1/3

    ①CD：需严控的最小线宽或孔径；②分辨率：能分开的最小线宽，R=k₁λ/NA；③NA=n·sinθ，浸没时 n=1.44；④overlay：层间套刻偏差，预算约线宽的 1/3。

2. ***阐述ArF光刻胶的化学特性及其曝光显影时的化学原理？***

    关键词：193 nm｜化学放大｜t-BOC＋PAG｜产酸脱保护成羧基｜TMAH 溶解

    ArF 胶用于 193 nm，属化学放大胶：脂环聚合物骨架＋酸可分解保护基 t-BOC＋光致产酸剂 PAG。曝光产酸，PEB 时酸催化脱保护生成羧基，曝光区溶于 2.38% TMAH；酸不消耗，一个光子引发上千次反应。

3. ***解释光刻过程中对准是如何实现的？***

    关键词：前层标记｜成像或衍射解算｜干涉闭环补偿｜畸变/热变形/标记不对称

    前层做好对准标记，如十字、盒中盒、光栅，光源照标记由成像或衍射信号解算 X/Y 与旋转，工件台用激光干涉闭环补偿后再曝光；误差来自镜头与掩膜畸变、晶圆热变形、标记不对称。

4. ***介绍投影掩膜版，解释其制造过程。***

    关键词：石英＋Cr｜4×/5×｜MoSi 衰减 PSM＋OPC｜贴 pellicle

    石英基板＋Cr 遮光层，图形按 4×/5× 做、物镜缩小投影；先进用 MoSi 衰减相移版 PSM＋OPC。流程：清洗→镀 Cr→涂胶→直写→显影→刻 Cr→去胶→修缺陷→贴防尘膜 pellicle。

5. ***DARC和BARC的区别是什么？***

    关键词：BARC 有机旋涂吸收｜DARC 无机 SiON 干涉相消｜兼硬掩膜

    BARC 是有机聚合物，旋涂，靠发色团吸收 193 nm 抑制反射，刻蚀时需单独开口；DARC 是无机 SiON，CVD 沉积，靠干涉相消，兼作硬掩膜随主刻蚀一起消耗。

6. ***描述光刻过程中涉及的主要步骤，包括匀胶，曝光，显影，烘烤等，以及说出每步中关键工艺参数的作用。***

    关键词：脱水＋HMDS 增黏｜t∝1/√ω｜软烘去溶剂｜剂量定 CD 焦距定清晰｜PEB 促酸扩散｜TMAH 定线宽｜坚膜抗刻蚀｜检测

    ①预处理 脱水＋HMDS 增黏；②匀胶 t∝1/√ω；③软烘 90–110 ℃ 去溶剂；④曝光 剂量定 CD、焦距定清晰；⑤PEB 110–130 ℃ 促酸扩散；⑥显影 2.38% TMAH，时间与温度定线宽；⑦坚膜 100–130 ℃ 增抗刻蚀与黏附；⑧检测 CD、套刻、缺陷。

7. ***如何在光刻工艺前如何对晶圆表面进行预处理？***

    关键词：150–200 ℃ 脱水｜HMDS 疏水｜O₂/UV 去残

    先脱水烘烤 150–200 ℃ 去吸附水，再用 HMDS 气相处理使表面疏水、提高黏附；必要时用 O₂ 等离子体或 UV-ozone 去有机残留，保证洁净平整。

8. ***为什么要有曝光后烘烤PEB？***

    关键词：提供活化能｜酸扩散平滑边缘｜抑驻波｜±0.5 ℃

    ①提供活化能，使酸催化脱保护完成，室温下几乎停滞；②酸适度扩散，平滑边缘、提高对比度；③抑制驻波。温度过高酸扩散过远致 CD 展宽，控温 ±0.5 ℃。

9. ***列举并讨论最常见的光刻胶显影方法及其关键显影参数。***

    关键词：puddle/paddle｜浓度·温度·时间·搅动·冲洗

    主流是水坑/桨式，英文 puddle/paddle，静止覆液：省液、温度匀、CD 一致性好；另有浸没式与喷淋式。参数：显影液浓度、温度、时间、覆盖与搅动方式、冲洗干燥方式。

10. ***说明显影后进行坚膜处理的原因。***

    关键词：去残溶剂｜致密抗刻蚀｜增黏附｜过热塌陷

    ①去残留溶剂与显影液，防后续放气；②胶膜致密化，提高抗干法刻蚀选择比；③增强黏附，防图形漂移脱落。温度过高会流动塌陷。

11. ***如何避免光刻胶的气泡？***

    关键词：回温脱气｜过滤排气｜针阀慢分配｜dummy dispense

    ①胶液回温脱气；②管路与过滤器排气，针阀慢速分配；③避免剧烈摇晃起泡；④涂布前 dummy dispense 预排；⑤在线过滤无气泡供液。

12. ***显影后光刻胶侧壁倾斜的原因？***

    关键词：显影过度｜PEB 过热｜驻波｜离焦/剂量不足｜缺 BARC｜黏附差

    ①显影过度；②PEB 过热酸扩散过远；③驻波效应；④离焦或剂量不足；⑤缺 BARC 致衬底反射；⑥黏附不良；⑦显影液温度不均。

13. ***光刻胶黏度性不好的原因及处理办法？***

    关键词：疏水不足/水汽｜HMDS 失效｜软烘不足｜污染｜冲洗不净

    按黏附性不良理解。原因：①表面疏水不足或含水汽；②HMDS 失效；③软烘不足残溶剂；④衬底污染或氧化；⑤冲洗不净。处理：脱水＋HMDS、优化软烘、清洗衬底、坚膜、加黏附层。

14. ***去胶过程中胶残留如何处理？***

    关键词：O₂ 灰化｜湿法去侧壁聚合物｜碳化胶强氧化｜DHF/SC-1 复检

    ①O₂ 等离子体灰化为主，配湿法，如 SPM 或有机胺去侧壁聚合物；②注入后碳化的胶用强氧化去胶；③高深宽比用下游微波等离子体减损伤；④DHF 或 SC-1 复检。

15. ***光刻胶膜层会有哪些缺陷？缺陷的检测方式有哪些？***

    关键词：针孔·颗粒·气泡·条纹·残胶·T-topping·LER｜光学暗场＋CD-SEM＋椭偏

    缺陷：针孔、颗粒、气泡、条纹、残胶、T-topping、侧壁倾斜、线边缘粗糙、塌陷剥离。检测：光学/暗场扫描、缺陷检测仪、CD-SEM 复查、椭偏与 OCD 测膜厚。

16. ***如何提高光刻工序中匀胶，显影的均匀性？***

    关键词：转速加速度｜EBR｜puddle 均匀｜queue time｜气流

    匀胶：控转速与加速度、胶温与黏度、EBR 去边、排风均匀；显影：puddle 静态均匀覆液、控温、喷淋均匀、缩短 queue time、稳定气流。

17. ***请说明自动对准四重图形化（SAQP）的主要工艺步骤。***

    关键词：mandrel 4×｜spacer 厚度＝线宽｜回刻｜去芯轴 2×｜再来一次 4×

    硬掩膜→光刻刻蚀出芯轴 mandrel，周期为 4×→共形沉积 spacer，厚度等于线宽→各向异性回刻只留侧壁→去芯轴，周期回到 2×→再重复一次得 4×→以 spacer 为掩膜刻目标层。

18. ***描述光刻机分辨率极限的瑞利公式是什么？其中各个参数的含义是什么？***

    关键词：R=k₁λ/NA｜DOF=k₂λ/NA²｜k₁ 0.25，量产 0.3–0.35

    R=k₁λ/NA，DOF=k₂λ/NA²。λ 波长，NA=n·sinθ 为数值孔径，k₁ 工艺因子，极限 0.25，量产 0.3–0.35，k₂ 焦深因子；NA 增大使焦深按平方下降。

19. ***光刻工艺中需要监控哪些参数？CD-SEM、光学OCD、套刻测量等工具分别用于监控什么指标？***

    关键词：CD/CDU｜套刻｜CD-SEM 形貌｜OCD 膜厚侧壁角｜overlay

    监控：胶厚均匀性、软烘/PEB 温度、剂量与焦距、显影液浓度温度时间、CD/CDU、套刻、缺陷、胺浓度、queue time。CD-SEM 测线宽与侧壁；OCD 反演 CD/膜厚/侧壁角；overlay 测层间偏差。

## 4、图形转移-刻蚀（刻蚀岗位常见面试题）

### 一页速记

| 项目 | 关键点 |
|---|---|
| RIE | 平行板，13.56 MHz 加下电极，鞘层加速离子 |
| ICP | 电感耦合高密度 10¹¹–10¹² cm⁻³，偏压独立控离子能量 |
| MFP | λ=k_BT/(√2πd²P)，与气压反比，常压约 65 nm |
| ALE | 改性＋低能 Ar⁺，每循环约一个原子层 |
| Bosch | SF₆ 刻蚀／C₄F₈ 钝化交替，侧壁有 scallop |
| 终点 | OES 光谱突变／激光干涉／质谱 |

气体口诀：*Si 用 Cl₂、HBr、SF₆；氧化硅用氟碳，如 CF₄、CHF₃、C₄F₈；氮化硅加 O₂；W 用 SF₆；Al/TiN 用 Cl₂、BCl₃；有机膜用 O₂*。

1. ***请描述RIE（反应离子刻蚀）工艺的工作原理和应用场景。***

    关键词：平行板｜13.56 MHz 加下电极｜鞘层加速｜化学＋垂直轰击

    平行板电容耦合，13.56 MHz 加下电极；自由基化学吸附＋鞘层离子垂直轰击协同，产物挥发抽走；用于介质、硅、金属图形转移。

2. ***什么是平均自由程（MFP）？***

    关键词：λ=k_BT/(√2πd²P)｜与气压反比｜常压 65 nm

    气体分子两次碰撞的平均距离，λ=k_BT/(√2πd²P)，与气压成反比：常压约 65 nm，低压等离子体可达毫米级。它决定离子能否无碰撞穿过鞘层，是低压才高方向性的原因。

3. ***什么是刻蚀残留物？***

    关键词：C-F 聚合物｜SiOₓF_y｜掩膜碎屑｜再沉积金属

    刻蚀后留在表面或侧壁的非挥发产物：C-F 聚合物、SiOₓF_y、掩膜碎屑、再沉积金属；会增大接触电阻、引起漏电，需原位清洗或湿法去除。

4. ***什么是原子层蚀刻（ALE）？在哪些应用场景特别有用？***

    关键词：自限制改性｜低能 Ar⁺ 去除｜每循环一原子层｜自限·低损伤

    把刻蚀拆成循环两步：①Cl₂/O₂ 等改性气自限制吸附改性表面；②低能 Ar⁺ 只打掉改性层。每循环约一个原子层，自限制、损伤极低；适合 FinFET/GAA 原子级修形与超薄层去除。

5. ***什么是电感耦合等离子体（ICP），ICP etching有什么优点？***

    关键词：线圈感应｜10¹¹–10¹² cm⁻³｜偏压独立｜低压高密度

    螺旋线圈射频感应耦合产生高密度等离子体，另加偏压射频独立控离子能量。优点：密度高达 10¹¹–10¹² cm⁻³、低压仍高速率、密度与能量解耦、方向性好，适合高深宽比刻蚀。

6. ***什么是etch stop layer？它在多层结构中的作用是什么？***

    关键词：反应极慢或产物不挥发｜自动终止｜放宽过刻

    与刻蚀气体反应极慢或产物不挥发的膜，如刻 SiO₂ 用 SiN、刻 Si 用 SiO₂；到界面自动终止，防底层被刻穿，并放宽过刻窗口。

7. ***选择刻蚀气体的标准有哪些？***

    关键词：产物挥发｜高选择比｜强钝化｜高速率｜无残留｜环保

    ①产物易挥发；②对掩膜与底层选择比高；③侧壁钝化强、各向异性好；④速率高、均匀性好；⑤无残留与腐蚀；⑥安全环保、成本可接受。

8. ***常见的薄膜材料和刻蚀气体有哪些？***

    关键词：Si：Cl₂ HBr SF₆｜SiO₂：CF₄ CHF₃ C₄F₈ C₄F₆｜SiN：CF₄+O₂ CH₂F₂｜W：SF₆｜Al/TiN：Cl₂ BCl₃｜有机：O₂

    Si：Cl₂、HBr、SF₆、CF₄；SiO₂：CF₄、CHF₃、C₄F₈、C₄F₆；SiN：CF₄＋O₂、CH₂F₂、SF₆；W：SF₆ 或 SF₆/Cl₂；Al/TiN：Cl₂、BCl₃、HBr；有机膜：O₂，Low-k 用 H₂/He；High-k：BCl₃/Cl₂、HBr。

9. ***如何确定刻蚀终止点？***

    关键词：OES 谱线突变｜激光干涉｜质谱｜定时兜底

    ①OES 监测产物特征谱线突变；②激光干涉数条纹换算深度；③质谱测产物分压；④按标定速率定时兜底；先进机台用原位光谱加算法逐片闭环。

10. ***在刻蚀过程中常用的掩膜材料有哪些？以及它们的优缺点？***

    关键词：胶：省事但选择比低｜SiO₂：对 Si 好刻氧差｜SiN：硬掩膜但应力大｜金属：选择比高但沾污

    光刻胶：省工序，但选择比低、易被离子轰击碳化；SiO₂：便宜、对 Si 选择比高，刻氧化物差；SiN：抗刻强可作硬掩膜，但应力大、需热磷酸去除；金属如 Al/TiN/W：选择比极高适 HAR，但沾污、难去除、易微掩膜。

11. ***影响干法刻蚀工艺中各向异性的主要参数有哪些？***

    关键词：偏压｜气压｜气体配比｜基片温度｜源功率｜掩膜形貌

    ①偏压，即离子能量；②气压，即离子散射；③气体配比，即钝化气流量；④基片温度，即聚合物挥发；⑤源功率与离子密度；⑥掩膜侧壁形貌。

12. ***什么是选择性刻蚀，如何在实际工艺中实现高选择性？***

    关键词：挥发体系｜侧壁钝化｜低离子能量｜控温｜stop 层

    只刻目标膜、不伤掩膜与底层。做法：①选生成挥发性产物的化学体系；②聚合物钝化保护侧壁；③降低离子能量；④控制温度；⑤加 etch stop 层。

13. ***在刻蚀工艺中，如何控制侧壁的形貌以避免倒锥形或梯形剖面？***

    关键词：钝化↔轰击平衡｜不足→钻蚀｜过强→正梯形夹断｜顶部不足→倒锥

    关键是平衡钝化与轰击：适度增加 C₄F₈/CHF₃ 沉积，用 O₂ 调聚合物量、提高偏压、控温使聚合物适度挥发、优化掩膜边缘、避免过刻。钝化不足→钻蚀；过强→正梯形甚至夹断；顶部不足→倒锥。

14. ***如何应对刻蚀过程中产生的侧壁聚合物沉积问题？***

    关键词：提高 F/C｜升偏压｜升温促挥发｜原位 O₂ 清腔｜分段＋清洗

    提高 F/C 比，加 CF₄、SF₆ 或适量 O₂ 夺碳、提高偏压、适当升温促挥发、每片后原位 O₂ 清腔、分段刻蚀并在段间清洗，并优化气体切换时序。

15. ***在刻蚀工艺中，为什么会出现刻蚀速率不均匀的现象？如何改善？***

    关键词：气流电场｜温度梯度｜ARDE｜负载效应｜开孔率

    原因：气流与电场不均、温度梯度、ARDE 即深宽比依赖、负载效应、开孔率不同。改善：优化喷淋头与排气、分区控温、分步刻蚀、调气压与功率、按图形密度补偿并留过刻。

16. ***刻蚀工艺中，如何检测和控制刻蚀深度？***

    关键词：干涉/OES/SEM/椭偏｜速率定时＋终点＋固定过刻

    检测：激光干涉/反射、OES、SEM 断面、椭偏或 OCD、称重与电容法。控制：标定速率定时＋原位终点判定＋固定过刻比例，按图形密度分别标定。

17. ***在多层结构的刻蚀过程中，如何避免底层被意外刻蚀？***

    关键词：stop 层｜高选择比配方｜降偏压｜OES＋限过刻｜界面降功率

    设 etch stop 层、选高选择比配方、降低偏压减少溅射、OES 终点＋限制过刻、接近界面时降功率、在线监测底层膜厚。

18. ***在刻蚀过程中，如何处理等离子体损伤和电荷积累问题？***

    关键词：低偏压｜脉冲｜高气压｜ALE｜泄放路径抑 notching

    降低偏压与离子能量、用脉冲等离子体、提高气压让离子碰撞失能、改用 ALE、HAR 结构留导电泄放路径抑 notching、加 UV 屏蔽、必要时退火修复。

19. ***如何处理刻蚀过程中由于掩膜与基材选择性不足导致的图形变形问题？***

    关键词：加厚或换硬掩膜｜提高选择比｜低能减侧蚀｜优化侧壁角

    加厚掩膜或改硬掩膜，如 SiN、金属、提高选择比配方、降低离子能量减少掩膜侧壁侵蚀、优化掩膜侧壁角、减少过刻并提高终点精度。

20. ***如何应对刻蚀过程中出现的微掩膜效应（micro-masking effect）？***

    关键词：微柱·草状·黑硅｜换挥发气体｜升温｜低偏压｜清腔换掩膜

    非挥发产物或掩膜碎屑局部遮挡，形成微柱、草状或黑硅。对策：选生成挥发性产物的气体、提高温度、降低偏压、加强排气、中途清洗、清腔与换掩膜。

21. ***如何评估等离子体刻蚀对器件性能的损伤？有哪些方法可以减少刻蚀损伤？***

    关键词：C-V·漏电·TDDB｜PL·椭偏｜TEM·AFM·SIMS｜减少同 4-18

    评估：电学用 C-V、漏电、界面态、TDDB，光学用 PL、椭偏，结构用 TEM、AFM、SIMS。减少：低偏压、脉冲等离子体、ALE、高气压、后处理退火或氧化修复。

22. ***在刻蚀高深宽比结构（如TSV、MEMS器件）时会遇到哪些技术挑战？如何通过工艺创新来解决这些问题？***

    关键词：进不去出不来 ARDE｜scallop｜notching｜Bosch SF₆/C₄F₈｜低温｜脉冲｜准 ALE

    挑战：反应物进不去、产物出不来，即 ARDE、Bosch 循环的扇贝纹 scallop、掩膜被斜向侵蚀、孔底电荷致 notching、填充与应力。对策：Bosch 循环，SF₆ 刻、C₄F₈ 钝、低温刻蚀、ICP 低压高密度、脉冲偏压、准 ALE。

23. ***针对Low-k材料、High-k材料、金属栅极等新兴材料，刻蚀工艺需要考虑哪些特殊因素？***

    关键词：Low-k 多孔易损 k↑→H₂/He 低偏压｜High-k HfO₂ 氧空位→Vth 漂｜金属栅 BCl₃/Cl₂ 防腐蚀·功函数

    Low-k：多孔易被 O₂ 与离子轰击损伤使 k 升高、变亲水，用 H₂/He 化学、低偏压、致密化；High-k 如 HfO₂：控化学计量与残留，防氧空位致阈值漂移；金属栅如 TiN/Al：防残留腐蚀，BCl₃/Cl₂＋原位钝化，注意功函数偏移。

[^1]: *1.2 垂直布里奇曼法 VB 法*

    原文：通过驱动石英安瓿向上移动，使生长界面产生相对运动。

    问题：原文同时设定「上部温度高于下部温度」，安瓿向上移动等于把正在结晶的界面送进更热的区域，晶体不会继续长大。VB 即坩埚下降法的通行动作是安瓿相对炉体向下穿过固定温场，凝固界面自下而上推进；也有固定安瓿、让加热器上移的等效做法。

    建议写法：安瓿下降，或加热区上移，凝固界面自下而上推进。
