# 输出 O
```
print()
```
`()`中：
- 字符串用`' '`或`" "`
- 多个字符串用`,`隔开
- `,`输出为一个空格%%不可连续用两个`,`%%
- 可直接打印整数及计算结果
- 参数
	- `sep`全称`separator`（分隔符）
	- `sep`的值可以是任意字符串
	- `sep`只在两个及以上参数时起作用
	- `end`与`sep`对比如下
	- `sep`、`end`都是字符串型参数变量，赋值时注意要用引号表示字符串值

| 参数    | 默认值       | 控制什么        | 生效条件   |
| ----- | --------- | ----------- | ------ |
| `sep` | `" "`（空格） | 多个参数之间用什么隔开 | 至少两个参数 |
| `end` | `\n`（换行）  | 输出最后补什么     | 任何情况   |

# 输入 I
```
input()
```
- 直接用`* = input()`即可赋值，`*`为变量名
- `input('A')`A会打印在终端，可用于提示用户输入信息
- 返回值为字符串
# 关于变量
- 可以为整数、浮点数、字符串等
- 可以直接写变量名打印变量内容
- 可以用`print(A)`打印变量A内容
