## 同步方式

- 远端：`git@github.com:R1s-t/obsidian-vault.git`（**SSH**）
- **网络注意**：本机 `github.com:443` 被单独阻断（直连能收到 32KB 后卡死，SNI 阻断），而 `api.github.com`、`codeload.github.com` 直连正常。所以：
  - 走 HTTPS 推拉**必须开着梯子**（git 全局已配 `http.proxy = http://127.0.0.1:12450`）
  - 走 SSH 不依赖梯子（`~/.ssh/config` 已配 `id_ed25519_github` 密钥）。**2026-10-30 起 `github.com:22` 被网络拒绝**，已把 `Host github.com` 指向 `ssh.github.com:443`（GitHub 官方 SSH-over-443 入口，同一把钥匙），实测可用
  - 梯子没开时，HTTPS 操作会先卡一轮超时再失败——此时用 SSH 即可
- 插件 Obsidian Git：自动提交 15 分钟一次（本地提交，不需要网络），推送手动（命令面板 `Obsidian Git: Push`），推送前自动拉取，同步方式 rebase
- **Obsidian 自动同步不需要开梯子**：远端走 SSH，而 SSH 不经过 HTTP 代理；现在经 `ssh.github.com:443` 出去，这条路是 HTTPS 端口，梯子开不开都能通。梯子只在纯 HTTPS 的 git 操作（如 `gh repo create --push`）才需要
- `~/.ssh/config` 里加了 `ConnectTimeout 10` / `ServerAliveInterval 15`，断网时 10 秒快速失败，不会让 Obsidian 卡住

## 其他设备接入

### 电脑（有 ssh 命令的）

1. `git clone git@github.com:R1s-t/obsidian-vault.git`
2. 该设备要有 SSH 私钥并注册到 GitHub
3. 用 Obsidian 打开克隆下来的目录即可 —— `.obsidian/` 已随库同步，15 个插件配置都带着

### 手机（Android / iOS）

**注意：手机端 obsidian-git 走的是 HTTPS，不是 SSH。** 插件在移动端用 isomorphic-git（纯 JavaScript 实现）替代桌面端的 git 命令，源码里会把 `git@github.com:...` 自动改写成 `https://github.com/...`，认证方式是用户名 + 密码/token：

1. 手机上 Obsidian → 设置 → 第三方插件 → 关闭「受限模式」→ 浏览 → 安装并启用 **Git**
2. 插件设置里填 `Author name` / `Author email`（与电脑保持一致：`Risttt` / `ris-ttt@outlook.com`）
3. 侧边栏 Git 图标 → **Clone remote repo** → URL 填 **HTTPS** 地址 `https://github.com/R1s-t/obsidian-vault.git` → 选一个空目录
4. 仓库是 public，**克隆不需要登录**；但推送到 GitHub 时会弹窗要凭据——用户名填 `R1s-t`，密码填 GitHub 的 PAT（personal access token，不是账号密码）
5. 克隆完成后在插件设置里开：开机自动拉取、每 10 分钟自动提交、同步方式选 rebase

手机端必须开梯子：手机上走的是 HTTPS，而 `github.com:443` 这条路本身是被阻断的（见上）。
