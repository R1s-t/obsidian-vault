# 字符编码
- 计算机只能处理数字，要将文本转换为数字
- `ASCII`编码
- 多语言混合的文本由于编码标准不同，会有乱码
- `Unicode`字符集，把所有语言统一到一套编码
- `Unicode`编码为两个字节，`ASCII`为一个字节
- `Unicode`的存储空间会比较大，故发明`UTF-8`编码
- `UTF-8`编码为可变长编码，可将`ASCII`编码视为`UTF-8`编码的一部分
- 计算机内存统一使用`Unicode`编码

# Python的字符串
- Python 3版本中字符串以`Unicode`编码，支持多语言
- 对于==单个字符==的编码
	- 函数`ord( )`获取字符的整数表示
	- 函数`chr( )`把编码转换为对应的字符
- 可以用十六进制写`str`，要在整数编码前写`\u`
- Python的字符串类型是`str`，在网络上或者磁盘中要变为以字节为单位的`bytes`
- Python对`bytes`类型的数据用`b`前缀的单引号或双引号表示
