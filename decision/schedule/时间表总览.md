## 桌面助手（不开 Obsidian 也能用）

双击桌面上的 **`时间表助手`** 快捷方式即可，它是一个独立的小窗口，不依赖 Obsidian 是否打开。

**界面上有什么**

| 位置 | 内容 |
| --- | --- |
| 顶栏 | 标题 + 右侧三个按钮：`同步`（绿，把勾选进度写回时间表「八、实际进度」并重读界面）· `周文件夹` · `本周文件`（直接打开这周的 md） |
| 顶栏副标题 | 今天几号星期几 · 当前周 · **距停项目 N 天** · **距初试 N 天** |
| 左栏 | 31 周一行，带日期和 `已完成/总数`；当前周高亮，未建周灰显；列表可滚 |
| 左栏右上 | `已建 n/31 周 · 总项数 · 完成 n` |
| 左栏底部 | **节奏对比**：`时间` 与 `任务` 两条细条——时间过了本阶段的百分之几 vs 任务做完了百分之几，任务条落后就是欠账；下面一行 `下一个硬节点：W09 · 01.09 寒假开始 · 还有 48 天` |
| 右上标题 | `W22 2027-04-05 ~ 04-11` + 阶段 · 计划工时 · 项数 · `还有 N 天开始`／`本周第 n/7 天`／`已过去` |
| 指标卡 | 标题下三张卡：**本周**（绿）· **本阶段**（蓝，如 `P0 · 8%`）· **全部**（灰），都是 `完成/总数 + 百分比` |
| 橙色条 | 这一周有硬节点时才出现，如 `⏰ 硬节点：05.07 初赛截止` |
| 任务区 | 一列到底，**每条任务后面都带工时**（`· 3h`）；做完划掉变灰；鼠标移上去整行浅底 |
| 底部 | 进度条（8px 细条）+ `本周 0/11 0% · 剩 11 项 ≈15h` |

- 打勾**直接写回** `周/*.md`（和 Obsidian 是同一份文件，不会产生第二份数据）
- 打勾后**界面上的数字立刻变**：三张指标卡、左栏那一行、底部进度条同步更新，不用点任何按钮；但**时间表的「八、实际进度」只在你点顶栏 `同步` 时才回填**，平时不会去写那个文件
- 滚动条**按需出现**：任务少时（如 W30 只有 5 项）不显示，多时（如 W10 有 16 项）才出现，不会出现「拖到一片空白」
- 快捷键：`←` `→` 切换上一周／下一周，`Ctrl+R` 同步，`Esc` 关闭
- 没建周单的周：标题下方显示「周单未建」，底部出现绿钮 `为这一周生成任务单`
- 备用入口：`_tools/打开时间表助手.cmd`（桌面快捷方式丢了就用它）
- 图标：窗口标题栏、任务栏、桌面快捷方式统一用 `_tools/时间表助手.ico`（深绿底 + 白勾）

## 周任务单

任务单按 `W01 ~ W31` 一周一篇，放在 `decision/schedule/` 里，文件名格式 `W{周号} 任务单（起~止）.md`。

下表自动统计，不用手填：

```dataview
TABLE WITHOUT ID
  file.link AS 周单,
  length(file.tasks) AS 项数,
  length(filter(file.tasks, (t) => t.completed)) AS 已完成
FROM "decision"
WHERE contains(file.name, "任务单")
SORT file.name ASC
```

> 任务是逐周手写的（`_tools/week_tasks.py` 里 31 周的清单），不是从逐周表一句话切出来的。每张单带三段：**这周任务 → 完成标准 → 下周怎么用**，能看出前后在干什么。任务单只管这一周，不追上周欠的账（没做完的自己找时间补）。已有周绝不覆盖；要重写加 `--force`（已勾的项会保留）。没列出来的周就是还没生成。
