## 桌面助手（不开 Obsidian 也能用）

双击桌面上的 **`时间表助手`** 快捷方式即可，它是一个独立的小窗口，不依赖 Obsidian 是否打开。

**界面上有什么**

| 位置 | 内容 |
| --- | --- |
| 顶栏副标题 | 今天几号星期几 · 当前周 · **距停项目 N 天** · **距初试 N 天** |
| 顶栏按钮 | `生成下一周`（绿）· `本周文件`（直接打开这周的 md）· `周文件夹` · `回填`（刷新时间表的「八、实际进度」）· `刷新` |
| 左栏 | 31 周一行，带日期和 `已完成/总数`；当前周高亮，未建周灰显 |
| 左栏底部 | `已建 n/31 周 · 总项数 · 完成 n` |
| 右上标题 | `W22 2027-04-05 ~ 04-11` + 阶段 · 计划工时 · 项数 · `还有 N 天开始`／`本周第 n/7 天`／`已过去` |
| 橙色条 | 这一周有硬节点时才出现，如 `⏰ 硬节点：05.07 初赛截止` |
| 任务区 | 一列到底，**每条任务后面都带工时**（`· 3h`）；做完划掉变色 |
| 底部 | 进度条 + `本周 3/9 33% · 剩 6 项 ≈9.5h` + `累计 12/11 (…)` |

- 打勾**直接写回** `周/*.md`（和 Obsidian 是同一份文件，不会产生第二份数据）
- 快捷键：`←` `→` 切换上一周／下一周，`Ctrl+R` 刷新，`Esc` 关闭
- 没建周单的周：标题下方显示「周单未建」，底部出现绿钮 `为这一周生成任务单`
- 备用入口：`_tools/打开时间表助手.cmd`（桌面快捷方式丢了就用它）

## 周任务单

任务单按 `W01 ~ W31` 一周一篇，放在 `周/` 里，文件名格式 `W{周号} 任务单（起~止）.md`。

下表自动统计，不用手填：

```dataview
TABLE WITHOUT ID
  file.link AS 周单,
  length(file.tasks) AS 项数,
  length(filter(file.tasks, (t) => t.completed)) AS 已完成
FROM "1-时间表/周"
SORT file.name ASC
```

> 骨架由脚本从时间表抽出，已有周绝不覆盖。没列出来的周就是还没生成。
