# Latex Suite 微电子片段速查

Latex Suite 是 Obsidian 的 LaTeX 加速插件——输入短触发词，按 `Tab` 展开为完整 LaTeX 代码。本文档列出所有可用片段（默认 + 微电子自定义）。

---

## 使用方法

1. 在数学公式 `$...$` 或 `$$...$$` 内输入触发词
2. 按 **`Tab`** 展开
3. 如果有占位符 `$0`，继续按 **`Tab`** 跳到下一个占位位置，**`Shift-Tab`** 回到上一个

## 三、自动功能

Latex Suite 还有一些**无需手动触发的功能**，已在你的配置中启用：

| 功能 | 说明 |
|------|------|
| **自动分数** | 输入 `12/34` 后按空格 → `\frac{12}{34}` |
| **自动下标** | 输入 `x3` → `x_{3}`（字母后跟数字自动转下标） |
| **矩阵快捷键** | 在 matrix 环境内按 `Tab` 新增列，`Enter` 新增行 |
| **Tab 跳出** | 在 `)` `]` `}` 等闭合符号后按 Tab，光标跳到外面 |
| **括号自动放大** | `\left` `\right` 配合 `sum` `int` `frac` 时自动添加 |

## 四、自定义片段的方法

需要添加新的微电子相关片段时，编辑以下文件：

```
.obsidian/plugins/obsidian-latex-suite/data.json
```

在 `"snippets"` 字段的数组中，按以下格式添加条目：

```javascript
{trigger: "触发词", replacement: "展开后的LaTeX", options: "mA", description: "说明"},
```

| options 值 | 含义 |
|-----------|------|
| `mA` | 仅在数学模式触发，自动展开 |
| `tA` | 在文本模式触发，自动展开 |
| `rmA` | 触发词为正则表达式，数学模式，自动展开 |
| `m` | 数学模式，手动触发 |

**注意**：编辑 `data.json` 后需要重启 Obsidian 才能生效。

## 五、使用建议

1. **先记高频的 10 个**——`gm`、`vth`、`vgs`、`ff`、`sq`、`ee`、`_`、`->`、`!=`、`ooo`。这些每天都要用几十次
2. **不要一次性背完**——用到时先来查这张表，用得多了自然就肌肉记忆了
3. **课上不要调试片段**——片段配置是周末归档时做的事情，课上老老实实手写纸笔
4. **禁止覆盖**——`sr` 已被默认占用（平方），压摆率请用 `slew`
