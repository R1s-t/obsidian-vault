# Linux 命令行速查

## 一句话

Windows 靠点鼠标，Linux 靠敲命令——**命令的价值是能被重复、写进脚本、隔着网络执行**。做数字 IC 躲不开它，因为工业界的 EDA 工具（Cadence、Synopsys、以及全部开源工具）都长在 Linux 上。

## 先认清三件事

### ① 一棵树，没有盘符

```
/                    根
├── home/ris-t/      你的家，简写 ~
├── usr/bin/         装的软件都在这（iverilog、verilator 都在这）
├── etc/             配置文件
├── tmp/             临时文件，重启清空
└── dev/             设备也当文件看（硬盘、终端皆如此）
```

### ② 提示符在告诉你三件事

```
ris-t@CaoKang:~$
 │      │      │└─ $ 表示普通用户（# 是 root）
 │      │      └── 当前目录（~ 就是家）
 │      └───────── 机器名
 └──────────────── 用户名
```

### ③ 没有回收站

`rm` 删掉就是删掉，没有"还原"。**铁律：敲 `rm` 之前先 `ls` 看一眼要删什么。**

## 十个命令，覆盖九成操作

| 命令      | 作用    | 例子                                        |
| ------- | ----- | ----------------------------------------- |
| `pwd`   | 我在哪   | `pwd`                                     |
| `ls`    | 这有什么  | `ls -l` 详细、`ls -a` 含隐藏                    |
| `cd`    | 去哪    | `cd dir`、`cd ..` 上一级、`cd ~` 回家、`cd -` 回上次 |
| `mkdir` | 建目录   | `mkdir -p a/b/c`（`-p` 连父目录一起建）            |
| `cp`    | 复制    | `cp a.v b.v`、`cp -r 目录1 目录2`              |
| `mv`    | 移动/改名 | `mv old.v new.v`（改名也是它，没有单独的 rename）      |
| `rm`    | 删除    | `rm a.v`、`rm -r 目录`（不可恢复）                 |
| `cat`   | 看文件   | `cat full_adder.v`                        |
| `less`  | 分页看   | `less 长文件`，`q` 退出                         |
| `grep`  | 搜内容   | `grep "assign" *.v`                       |

补充三个：

| 命令 | 作用 |
|------|------|
| `find . -name "*.v"` | 按名字找文件 |
| `wc -l file` | 数行数 |
| `man ls` | 查手册，`q` 退出 |

## 三个救命键

比多记十个命令有用：

| 键 | 作用 |
|------|------|
| `Tab` | 自动补全。敲 `cd proj` 按 Tab 补成 `projects`——目录名的记忆负担直接消失 |
| `↑` `↓` | 翻历史命令，刚才敲错的调出来改 |
| `Ctrl+C` | 中断当前命令。卡住了、跑飞了都用它 |

## 管道与重定向

**管道 `|`**：前一条的输出变成后一条的输入。

```bash
ls -l | grep ".v"          # 只列 .v 文件
cat build.log | tail -20   # 看日志最后 20 行
iverilog -V | head -1      # 只留第一行
```

**重定向**：`>` 覆盖写文件，`>>` 追加。

```bash
make > build.log 2>&1     # 正常输出和错误都写进 build.log
```

`2>&1` = 把错误流（2）也并到正常流（1）去的地方。抄着用即可。

## 权限与 sudo

`ls -l` 会看到：

```
-rwxr-xr-x 1 ris-t ris-t 1234 Nov 9 13:00 verilator_test
 │└┬┘└┬┘└┬┘
 │ │  │  └── 其他人：读+执行
 │ │  └───── 同组：读+执行
 │ └──────── 自己：读+写+执行
 └────────── 类型（- 文件，d 目录）
```

`rwx` = 读、写、执行。

`sudo` = 临时当管理员。`apt install` 要加它，因为往 `/usr/bin` 写东西需要 root 权限。

**原则：只在装软件、改系统配置时用 `sudo`；写代码永远不用**（项目在 `~/projects` 下，本来就属于你）。

## 编辑器 nano

| 键 | 作用 |
|------|------|
| `Ctrl+O` | 保存（回车确认文件名） |
| `Ctrl+X` | 退出 |
| `Ctrl+K` | 删除当前行 |
| `Ctrl+W` | 搜索 |

屏幕底部两行常驻这些提示，`^` 就是 Ctrl。

**`vim` 逃生**：不小心进了 `vim`，按 `Esc`，输入 `:q!` 回车（不保存强制退出）。

## 真正要记住的只有三条

1. `rm` 没有回收站
2. `Tab` 能补全
3. `Ctrl+C` 能救你

其余靠两周的重复使用自然记住，不需要背。
