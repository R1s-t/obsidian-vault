# 考研库 · 使用说明

一个**纯备考管理**的 Obsidian 库:只管计划、进度、错题、真题、复盘、倒计时。
专业课知识笔记继续留在 `微电子笔记库`,这里不重复记录。

## 一、首次配置(一次性,约 5 分钟)

1. **用 Obsidian 打开本库**:「打开文件夹作为库」→ 选 `Documents/考研库`
2. **启用核心插件**:设置 → 核心插件,打开
   - 日记(Daily notes)
   - 模板(Templates,可选;装了 Templater 后可不依赖它)
3. **安装社区插件**:设置 → 第三方插件 → 关闭安全模式 → 浏览社区插件,装这 4 个:
   - **Templater**(模板引擎,动态填日期)
   - **Dataview**(查询 / 主页仪表盘)
   - **Tasks**(任务打卡、错题到期提醒)
   - **Calendar**(日历,点日期跳当日计划,推荐)
4. **设 Templater**(关键,让日计划自动填日期):
   - Templater 设置 → `Template folder location` = `Templates`
   - 打开 `Trigger Templater on new file creation`
   - 日记设置(核心插件)→ 模板文件 = `Templates/日计划模板`

## 二、目录结构

| 文件夹 | 用途 |
|--------|------|
| 00-主页 | 仪表盘:倒计时、各科进度、待复习错题 |
| 10-计划/日计划 | 每日计划(日记自动生成) |
| 10-计划/周计划 | 周计划 |
| 10-计划/阶段计划 | 基础 / 强化 / 冲刺里程碑 |
| 20-进度 | 每科一个进度文件(改 frontmatter 的 progress 数字即可) |
| 30-错题本 | 每科一个台账(任务格式,记资料 + 题号) |
| 40-真题 | 每科一个日志(年份 + 分数) |
| 50-复盘 | 日 / 周 / 月复盘 |
| 60-里程碑与倒计时 | 报名、初试等关键日期 |
| Templates | 模板文件 |
| Attachments / Inbox | 附件 / 收件箱 |

## 三、每日使用流程

1. **早上**:打开今日日记(点左侧日历,或 `Ctrl+P` → 打开今日日记),列三件大事 + 各科任务
2. **白天**:复习;遇到错题 → 在 `30-错题本/对应科目` 加一行任务,标 📅 复习日期
3. **晚上**:今日日记底部写一句复盘;更新 `20-进度` 里各科的 `progress` 数字
4. **每周日**:写周计划 + 周复盘
5. 看**主页**,它自动汇总:倒计时、各科进度条、今天该复习的错题

## 四、关键约定

- **错题**:`- [ ] 资料名 题号 📅 下次复习日期`,不抄题目(纸面为主)
- **真题**:只记年份 + 分数 + 备注,不抄题
- **进度**:改 `20-进度/xx.md` 顶部的 `progress` 数字(0-100),主页进度条自动变

## 五、git

库已用 git 管理,`.gitignore` 已忽略 `workspace.json` 等本地缓存。首次提交前确认无误即可。
